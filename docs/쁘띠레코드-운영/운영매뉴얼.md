결제 예시

| 예시 | 계산 | 결제 금액 |

촬영 구성은 "하나만" 골라야 하지만 네이버가 이를 막아 주지 못한다. 안내 문구만 있고, 대표가 예약 내용과 시트에서 확인한다. (→ 2-2)

## 2. 새 예약이 들어왔을 때 (알림 받고 바로 · 1~2분)

| 순서 | 어디서 | 무엇을 | 확인 |
|---|---|---|---|
| 1 | 네이버 달력 | 예약 **바로 뒤 1시간(정리)** 막기 | 달력에 막혔는지 보기 |
| 2 | 네이버 예약 상세 | 내용 확인: 촬영 구성이 하나만인가 · 패밀리면 4시간 이상인가 · 보증금이 들었나 · 추가 질문 4개 답이 있나 | 안 맞으면 → 2-2 |
| 3 | 시트 | 한 줄 입력: 이름 · 전화(010-1234-5678 모양) · 이용일 · 시작 · 종료 · 구성 · 방문인원 · 추가인원옵션 · 결제금액 · 테마 | 방문인원 · 결제금액은 **숫자만** |
| 4 | 시트 | 맞는금액 · 차액이 자동 계산됨 → 차액 칸 색 보기 | 0이면 다음 · 빨강/주황이면 → 2-1 |
| 5 | 아카라 | 정기 비밀번호 만들기: 이용일 · 시작 15분 전 ~ 종료 15분 후 | 만든 비밀번호 적어 두기 |
| 6 | 시트 | **비밀번호 입력 + 상태 '확정'** | 둘 다 넣어야 ① 나감 |
| 7 | 시트 (10분 뒤) | ① 결과 칸이 "성공"인지 | "실패: …"면 → 8-2 |
| 8 | 채팅방 | 손님 "확인" 답장이 오면 → 시트 비번확인 칸 **'답장'** | 전날 21시까지 없으면 전화 (→ 3) |

시트 입력은 대화창에 예약 내용을 주고 Claude에게 맡겨도 된다. 그래도 5~6번(비밀번호 · '확정')은 대표가 직접 한다.

### 2-1. 차액이 0이 아닐 때

| 차액 칸 | 뜻 | 하는 일 | 끝나면 |
|---|---|---|---|
| 빨강 (+) | 손님이 덜 냄 | 채팅방으로 부족한 금액과 계좌 안내 → 입금 확인 | 시트 **차액처리** 칸 표시 |
| 주황 (−) | 손님이 더 냄 | 네이버 예약(확정 상태)에서 남는 옵션만 부분 환불 | 시트 **차액처리** 칸 표시 |

### 2-2. 예약 내용이 규칙에 안 맞을 때

| 상황 | 하는 일 |
|---|---|
| 촬영 구성을 안 골랐음 | 채팅방이나 전화로 연락 → 베이직/패밀리 중 하나 고르게 함 → 시트에 구성 입력 → 부족한 돈은 2-1 빨강 순서 |
| 베이직 · 패밀리 둘 다 골랐음 | 연락 → 하나로 정리 → 더 낸 옵션 돈은 2-1 주황 순서(부분 환불) |
| 패밀리인데 4시간 미만 | 연락 → 4시간 이상으로 늘리거나 베이직으로 바꾸기 → 시트 · 달력 고치기 |
| 시트 줄이 빨강 | 위 문제를 시트가 잡아낸 것. 손님과 정리한 뒤 시트를 고치면 색이 사라짐 |

## 5. 퇴실 후 · 밤 9시 마감 (매일)

| 순서 | 어디서 | 무엇을 |
|---|---|---|
| 1 | 매장 | 오늘 이용한 팀 점검: 사진 · 소품 · 의상 · 기념일 세팅 · 기준은 **"다음 손님에게 다시 쓸 수 있나"** |
| 2 | 네이버 · 시트 | 파손 없음 → 5-1 / 파손 있음 → 5-2 |
| 3 | 채팅방 · 계좌 | 리뷰 이벤트 지급 → 5-3 |

### 5-1. 보증금 환불 (파손 없음) — 순서를 지킨다

| 순서 | 무엇을 | 왜 |
|---|---|---|
| 1 | 네이버 예약 화면에서 **'보증금' 옵션만 부분 환불** (50,000원 전액) | 환불 금액에 수수료 없음 (네이버페이 확인) |
| 2 | **그 다음에** 네이버 **'이용완료'** 누르기 | 완료를 먼저 누르면 부분 환불이 안 되고, 페이센터에서 따로 취소해야 하며 충전금이 필요하다 → 피한다 |
| 3 | 시트 보증금 칸 **'환불완료'** | 노랑(보증금 처리 남음)이 사라진다 |

### 5-2. 파손 있음 (⑤)

| 순서 | 무엇을 |
|---|---|
| 1 | 보증금 옵션은 **환불하지 않은 채로** 네이버 '이용완료' 누르기 |
| 2 | 시트에 **점검내용** · **차감금액**(숫자만) 입력 → 보증금 칸 **'차감(⑤발송)'** |
| 3 | ⑤ 매장점검결과안내가 자동으로 나감 (반환 계좌 요청) · 셋 중 하나라도 비면 ⑤ 결과 칸 "대기:" → 빈 칸을 채우면 나감 |
| 4 | 손님이 채팅방에 계좌를 보내면 **50,000원 − 차감금액**을 이체 → 장부 기록 |

배상 기준은 "다음 손님에게 다시 쓸 수 있나"이다. 다시 쓸 수 있으면 차감하지 않는다.

### 5-3. 리뷰 이벤트

| 조건 | 지급 | 방법 |
|---|---|---|
| 네이버 리뷰 사진 3장 이상 | **10,000원** | 손님이 채팅방에 캡처 + 계좌 → 확인 후 계좌 이체 |
| 블로그 사진 3장 이상 | **20,000원** | 손님이 채팅방에 링크 + 계좌 → 확인 후 계좌 이체 |

지급한 내용은 장부에 적는다.

## 6. 취소 · 변경

- 채팅방으로 받는다. 대표가 네이버에서 직접 처리한다.
- 기준 시각 = 이용 시작 시각.
- **보증금 50,000원은 어떤 경우에도 전액 환불.** 네이버 취소 수수료는 이용료에만 적용되고 보증금은 건드리지 않는다.
- 손님이 네이버에서 직접 취소하면 수수료 규칙이 그대로 적용될 수 있으니, 채팅방으로 먼저 연락받는 쪽이 안전하다.

### 6-1. 이용료 환불 비율

| 연락 시점 (이용 시작 시각 기준) | 이용료 | 보증금 |
|---|---|---|
| 3일 전까지 | **100%** | 전액 |
| 3일 전 ~ 24시간 전 | **50%** | 전액 |
| 24시간 이내 · 시작 전 | **30%** 환불 또는 **1회 변경** | 전액 |
| 시작 후 | 환불 없음 · 당일 변경만 | 전액 |
| 연락 없이 안 옴 | 환불 · 변경 없음 | 전액 |
| 매장 사정 | **100%** | 전액 |

### 6-2. 취소 처리 순서

| 순서 | 어디서 | 무엇을 |
|---|---|---|
| 1 | 채팅방 | 연락 시점 확인 → 환불 비율 안내 |
| 2 | 네이버 | 취소 처리 (이용료는 비율대로 · 보증금은 전액) |
| 3 | 아카라 | 비밀번호 삭제 |
| 4 | 시트 | 상태 **'취소'** (회색) |
| 5 | 네이버 달력 | 막아 둔 정리 1시간 풀기 |
| 6 | 아카라 | 소등 칸 끄기 (이미 넣었다면) |

### 6-3. 변경 처리 순서

| 순서 | 어디서 | 무엇을 |
|---|---|---|
| 1 | 채팅방 | 변경 가능한지 확인 (24시간 이내는 1회 · 시작 후는 당일만) |
| 2 | 네이버 | 시간 직접 조정 · 옛 자리 뒤 정리 1시간 풀고 새 자리 뒤 1시간 막기 |
| 3 | 아카라 | 옛 비밀번호 삭제 → 새 기간으로 정기 비밀번호 다시 만들기 |
| 4 | 시트 | 이용일 · 시작 · 종료 · 비밀번호 고치기 → **① 결과 칸 지우기** → ① 다시 나감 |
| 5 | 아카라 | 소등 칸을 새 종료 시각으로 |
| 6 | 채팅방 | 손님 "확인" 답장 → 비번확인 '답장' |

## 8. 시트 읽는 법

### 8-1. 색

| 색 | 뜻 | 할 일 |
|---|---|---|
| 빨강 | 알림톡 실패 · "발송중"이 멈춘 채 남음 · 시간 오류(종료가 시작보다 빠름) · 구성 미선택/중복 · 패밀리 4시간 미만 · 덜 낸 차액 | 사유를 고친 뒤 결과 칸 지우기(다시 보냄) · 손님 연락 |
| 주황 | 더 낸 차액 · 제목 줄이 주황이면 시험 모드 | 남는 옵션 부분 환불 · 시험 모드는 끄기 (8-2) |
| 노랑 | "대기:" (비밀번호 · 점검내용 · 시간 입력 필요) · 비번 미확인 · 보증금 처리 남음 | 빈 칸만 채우기 (결과 칸은 지우지 않기) |
| 회색 | 취소 | 없음 |

### 8-2. ①②⑤ 결과 칸 글자

| 적힌 글자 | 뜻 | 할 일 |
|---|---|---|
| 성공 | 나감 | 없음 |
| 실패: … | 안 나감 | 사유 고친 뒤 **결과 칸 지우기** → 다시 보냄 (②는 이용완료 상태여도 됨) |
| 대기: … | 빠진 칸이 있음 | 지우지 말고 빠진 칸만 채우기 |
| 발송중 (빨강으로 남음) | 보내다가 멈춤 | 솔라피 발송 내역에서 그 시각에 나갔는지 확인 → 나갔으면 결과 칸에 **'성공 수동확인'** / 안 나갔으면 칸 비우기 |
| 성공 응답해석실패-솔라피내역확인 | 나갔을 수도 있음 | **지우지 말고** 솔라피 발송 내역 확인 |
| 메모 칸 "② 보류: …" | ① 뒤에 시작 · 종료가 잘못 고쳐짐 | 시작 · 종료를 바로잡으면 ② 자동 |
| Z1 칸 '마지막 실행'이 20분 넘게 그대로 | 자동 발송이 꺼짐 | 메뉴 [쁘띠레코드] → **② 자동 발송 켜기** |
| 제목 줄이 주황 | 시험 모드 (알림톡이 손님이 아니라 시험 전화로 감) | 설치 가이드대로 시험 모드 끄기 → 제목 줄이 보라로 돌아오면 정상 |

결과 칸(①②⑤)은 지울 때 경고가 뜬다. 다시 보낼 때만 지운다.

## 9. 이럴 땐 이렇게

### 9-1. 예약 · 결제

| 이럴 땐 | 이렇게 |
|---|---|
| 새 예약 알림이 왔다 | 달력 뒤 1시간 막기 → 시트 입력 → 차액 → 비밀번호 → '확정' (2장) |
| 손님이 전화 · 카톡으로 예약하고 싶다고 한다 | 네이버 예약 링크로 안내. 결제가 네이버에서만 되므로 |
| 촬영 구성을 안 골랐거나 둘 다 골랐다 | 손님께 연락해 하나로 정리 → 차액은 2-1 |
| 패밀리인데 4시간 미만이다 | 손님께 연락 → 4시간 이상으로 늘리거나 베이직으로 |
| 차액 칸이 빨강(덜 냄) | 채팅방으로 부족한 금액 · 계좌 안내 → 입금 확인 → 차액처리 |
| 차액 칸이 주황(더 냄) | 네이버 예약(확정 상태)에서 남는 옵션만 부분 환불 → 차액처리 |
| 손님이 시간을 바꾸고 싶다고 한다 | 6-3 변경 순서 · 24시간 이내는 1회만 · 시작 후는 당일만 |
| 손님이 취소한다 | 6-1 비율로 이용료 환불 · 보증금은 전액 · 6-2 뒷정리 |
| 예약 마감(전날 19시) 뒤에 예약 문의 | 그 날짜는 받지 않음 · 다른 날짜로 안내 |

### 9-2. 알림톡 · 시트

| 이럴 땐 | 이렇게 |
|---|---|
| 비밀번호와 '확정'을 넣었는데 ①이 안 나간다 | 10분 기다리기 → 그래도 없으면 결과 칸 글자 확인 (8-2) → Z1 '마지막 실행' 시각 확인 → 멈췄으면 ② 자동 발송 켜기 |
| ① 결과가 "대기: 비밀번호 입력 필요" | 비밀번호 칸 채우기 (결과 칸은 지우지 않기) |
| ① 결과가 "실패: …" | 사유(전화번호 모양 등) 고치기 → 결과 칸 지우기 → 다시 나감 · 문자로도 안 가면 전화로 비밀번호 안내 |
| 손님이 "확인" 답장을 안 한다 | 전날 21시까지 기다렸다가 전화 → 확인되면 '답장' |
| ① 보낸 뒤 시간이 바뀌었다 | 시트 시작 · 종료 · 비밀번호 고치기 → ① 결과 칸 지우기 → 새 비밀번호로 다시 나감 |
| 메모 칸에 "② 보류: …" | 시작 · 종료가 잘못 고쳐진 것 → 바로잡으면 ② 자동 |
| "발송중"이 빨강으로 남아 있다 | 솔라피 발송 내역 확인 → 나갔으면 '성공 수동확인' / 안 나갔으면 칸 비우기 |
| 알림 메일이 왔다 | 메일의 시트 링크로 들어가 빨강 칸 확인 → 8-2 |
| 카톡이 아니라 문자로 나갔다 | 정상 (카톡 실패 시 자동 대체) · 손님 답장은 010-5162-9870 폰에서 확인 |
| 시트 제목 줄이 주황이다 | 시험 모드 → 설치 가이드대로 끄기 · 끄기 전에 시험 줄을 먼저 지운다 |
| 시트 Z1 '마지막 실행'이 20분 넘게 그대로 | 메뉴 [쁘띠레코드] → ② 자동 발송 켜기 |

### 9-3. 이용 당일

| 이럴 땐 | 이렇게 |
|---|---|
| "문이 안 열려요" | 채팅방(또는 전화)으로 비상 비밀번호 전달 · 도어락이 먹통이면 비상 열쇠 |
| 입장 알림이 안 온다 | 채팅방으로 상황 확인 |
| 연장하고 싶다 | 뒤 예약이 비었나 확인 → 1시간 50,000원 송금 QR → 소등 칸 종료 시각 늦추기 · 뒤 예약 있으면 불가 |
| 추가 인화 · 액자 | 매장 송금 QR → 입금 확인 |
| 손님이 퇴실 버튼을 안 눌렀다 | 종료 +15분에 자동 소등 · 그래도 안 꺼지면 새벽 1시 전체 소등 |
| 소등 칸을 안 넣고 전날을 넘겼다 | 당일이라도 아카라 소등 칸에 종료 시각 입력 |

### 9-4. 보증금 · 환불 · 리뷰

| 이럴 땐 | 이렇게 |
|---|---|
| 이상 없이 끝났다 | **'이용완료' 누르기 전에** 보증금 옵션만 부분 환불 → '이용완료' → 시트 '환불완료' |
| 실수로 '이용완료'를 먼저 눌렀다 | 예약 화면 부분 환불이 안 됨 → 네이버 페이센터에서 직권취소(충전금 필요). 번거로우니 다음부터는 순서를 지킨다 |
| 파손이 있다 | 보증금 환불하지 않고 '이용완료' → 시트 점검내용 · 차감금액 · '차감(⑤발송)' → ⑤ 자동 → 계좌 받아 남은 돈 이체 |
| 차감할지 애매하다 | 기준 하나: "다음 손님에게 다시 쓸 수 있나" · 쓸 수 있으면 차감하지 않음 |
| ⑤ 결과가 "대기:" | 점검내용 · 차감금액 · '차감(⑤발송)' 중 빈 것 채우기 |
| 손님이 리뷰 캡처 · 링크와 계좌를 보냈다 | 사진 3장 이상 확인 → 네이버 10,000원 / 블로그 20,000원 계좌 이체 → 장부 |
| 손님이 네이버에서 직접 취소했다 | 보증금이 전액 돌아갔는지 확인 · 이용료가 6-1 비율과 다르게 환불됐으면 손님께 연락해 맞추기 · 6-2 뒷정리 |
| 매장 사정으로 못 받는다 | 100% 환불 (보증금 포함) → 손님께 먼저 연락 |

### 9-5. 그 밖에

| 이럴 땐 | 이렇게 |
|---|---|
| 솔라피 잔액이 적다 | 충전 (매주 확인) |
| 도어락 배터리 경고 | 교체 · 비상 열쇠 위치 확인 |
| 인화지 · 액자가 떨어져 간다 | 주문 (매주 확인) |
| 아카라에 지난 비밀번호가 쌓였다 | 매주 삭제 |
| 남편이 대신 처리해야 한다 | 채팅방 관리자 · 시트 편집자이므로 이 매뉴얼 그대로 따라 하면 됨 |
