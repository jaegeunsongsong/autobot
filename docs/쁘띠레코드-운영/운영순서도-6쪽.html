자동으로 되는 일 대표가 하는 일 판단 · 읽는 법
대표새 예약 알림이 올 때 (순서대로)
  1. 네이버 달력에서 뒤 1시간(정리) 막기
  2. 시트에 한 줄 입력
  3. 차액 칸 확인 (빨강 → 계좌 안내 / 주황 → 부분 환불)
  4. 아카라 정기 비밀번호 만들기
  5. 시트에 비밀번호 + '확정' → ① 자동
대표전날 21시
  • 비번확인 칸 노랑 → 전화로 확인
  • 아카라 소등 칸에 종료 시각 입력 (+15분 소등)
대표매주 한 번
  • 아카라 지난 비밀번호 삭제 · 솔라피 잔액 확인
  • 도어락 배터리 · 인화지 · 액자 재고
대표매일 밤 9시 (한 번에)
  1. 오늘 이용한 팀 매장 점검 (기준: 다음 손님에게 다시 쓸 수 있나)
  2. 이상 없음 → 꼭네이버 '이용완료' 누르기 전에 보증금 옵션만 부분 환불 (50,000원) → 그 다음 '이용완료' → 시트 '환불완료'
  3. 파손 있음 → 보증금 환불하지 않고 '이용완료' → 시트에 점검내용 · 차감금액 → '차감(⑤발송)' → ⑤ 자동 → 계좌 받아 남은 돈 이체
  4. 리뷰 이벤트 지급 (네이버 10,000원 · 블로그 20,000원 계좌 이체)
  5. 장부 정리 · 시트에 빨강·노랑 칸이 남아 있지 않은지 확인
자동시트가 알아서 하는 것
