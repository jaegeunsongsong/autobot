# 2026학년도 2학기 1차 정기시험 가정통신문 검토

조선대학교부속고등학교 1·2·3학년 가정통신문 3종(시행일 2026. 9. 10.)을 원본 HWPX에서 추출해 대조한 결과다.

즉시 수정 4건, 수정 권장 15건, 다듬기 18건.

## 즉시 수정

### 시간표 제목만 다른 학기·다른 차수를 가리킵니다

- 위치: 붙임 1 · 제목
- 대상: 1학년

원문

```
2026학년도 1학기 2차 정기시험 시간표(1학년)
```

고침

```
2026학년도 2학기 1차 정기시험 시간표(1학년)
```

같은 문서의 제목, 본문 붙임 목록, 바로 다음 장 붙임 2 제목은 모두 **2학기 1차**입니다. 2·3학년 문서의 같은 자리도 맞게 되어 있습니다.

학부모가 가장 먼저 찾아보는 표의 제목이라, 이 표가 이번 시험 것이 맞는지 되묻는 전화가 옵니다.

### 금지 표현이 빠져 뜻이 정반대가 되었습니다

- 위치: 붙임 3 · 10번
- 대상: 1학년, 2학년, 3학년

원문

```
10. 시험 종료령 후에는 답안지 교체 및 답안을 수정. (시험 종료령 후에도 답안지를 수정 및 작성하는 경우 부정행위로 처리합니다.)
```

고침

```
10. 시험 종료령 후에는 답안지 교체 및 답안 수정을 할 수 없습니다. (시험 종료령 후에도 답안지를 수정 및 작성하는 경우 부정행위로 처리합니다.)
```

앞 문장이 `수정.`에서 끊겨 서술어가 없습니다. 글자대로 읽으면 종료령 뒤에 고치라는 말이 되어, 바로 뒤 괄호와 반대입니다.

0점 처리로 바로 이어지는 조항이라 이 문장 자체가 처분의 근거가 됩니다.

### 성적을 언제 어떤 방법으로 확인하는지 없습니다

- 위치: 붙임 4 · 기간 2번
- 대상: 1학년, 2학년, 3학년

원문

```

```

성적을 어디에서 보는지도 없습니다. 나이스 학부모서비스인지 성적표 배부인지에 따라 학부모가 할 일이 달라집니다.

### 인용한 훈령이 학교 시험용이 아니고 옛 판입니다

- 위치: 붙임 3 · 유형표 머리말
- 대상: 1학년, 2학년, 3학년

원문

```
※ 부정행위 유형 기준 (교육부 훈령 269호)
```

교육부훈령 제269호는 「대학수학능력시험 부정행위자 처리규정」의 2018. 8. 22. 시행본입니다. 이후 제456호(2023. 9. 22. 일부개정)로 바뀌었습니다.

학교 정기시험의 부정행위 기준은 「고등학교 학업성적관리 시행지침」과 학교 학업성적관리규정이 근거이므로, 근거를 학교 규정으로 바꾸는 편이 정확합니다.

같은 붙임 뒤쪽의 「학교생활기록 작성 및 관리지침」 **교육부훈령 제555호**는 2026. 3. 1. 시행본으로 정확한 인용입니다.

규정대로 학년실에 맡긴 학생도 문언상 부정행위자가 되어 두 문장이 충돌합니다.

### 0점 처리 범위가 두 가지로 읽힙니다


고침


"시험 당일 이전 교시"가 그날의 앞 교시를 뜻하는지, 그 전날까지를 뜻하는지 갈립니다.

이 학교는 하루에 여러 교시로 시험이 흩어져 있어, 해석 차이가 그대로 0점 과목 수의 차이가 됩니다.

고침

```
6. OMR 카드의 학년·반·번호·이름·과목명은 흑색 볼펜으로 적고, 답안 마킹은 컴퓨터용 사인펜(흑색)만 사용합니다.
```

※는 OMR 답안지의 **모든 글씨**를 볼펜으로 쓰라고 하는데, 6번은 인적사항까지 사인펜으로 쓰는 것처럼 읽힙니다. 서술형 답안은 9번이 볼펜으로 정리해 두었지만 인적사항은 두 갈래로 남습니다.

6번 `컴퓨터용 수성사인펜`과 7번 `컴퓨터용사인펜`은 이름도 띄어쓰기도 달라, 서로 다른 두 가지를 챙겨야 하는지 헷갈립니다.

서술형도 ※는 `흑(청)색 펜`, 9번은 `흑(청)색 볼펜`으로 갈립니다. 젤펜이나 플러스펜을 쓴 학생이 나오면 감독 교사마다 판단이 달라집니다.

### 시간표의 로마숫자가 전부 영문 소문자 l로 입력돼 있습니다

- 대상: 2학년, 3학년

원문

```
영어ll · 미적분l · 물리학ll · 지구과학ll · 화학ll · 생명과학ll · 일본어 회화l
```

고침

```
영어Ⅱ · 미적분Ⅰ · 물리학Ⅱ · 지구과학Ⅱ · 화학Ⅱ · 생명과학Ⅱ · 일본어 회화Ⅰ
```

붙임 2 범위표는 정상 로마숫자를 씁니다. 소문자 `l`은 글꼴에 따라 숫자 1이나 대문자 I로 보여 과목이 달라 보입니다.

띄어쓰기까지 합치면 두 표에서 다르게 적힌 과목이 **3학년 20개, 2학년 5개**입니다. 대응 자체는 모두 맞으니 표기만 한쪽 기준으로 통일하면 됩니다.

시간표를 한 번에 소문자로 적은 것으로 보이니, 하나씩 고치기보다 표 전체를 훑어 바꾸는 편이 안전합니다.

### 빠진 날짜와 학년별 시작일 차이를 설명하지 않습니다

- 위치: 본문 · 시행 기간
- 대상: 1학년, 2학년, 3학년

원문

```
1학년 — 시행 기간: 2026년 10월 6일(화)~10월 8일(목)
2·3학년 — 시행 기간: 2026년 10월 2일(금)~10월 8일(목)
```

1학년 통신문에는 2·3학년이 시험을 보는 10월 2일(금)에 1학년이 등교하는지, 정상 수업인지가 없습니다.

2·3학년 통신문은 기간을 10월 2일부터라고만 해서, 10월 3일(토) 개천절과 10월 5일(월) 대체공휴일 때문에 시험이 없는 사실이 드러나지 않습니다. 시간표에서는 10/2 다음이 곧바로 10/6입니다.

"10. 3.(토) 개천절, 10. 5.(월) 대체공휴일 제외" 한 줄이면 충분합니다.

### 누리집 로그인이 필요하다면서 계정 안내가 없습니다

- 위치: 본문 · 4번, 머리글
- 대상: 1학년, 2학년, 3학년

원문

```
4. 교과별 교수학습 및 평가 운영 계획: 학교 누리집 탑재 - 학교 누리집 >> 로그인 >> 교육활동 >> 학교시험정보
머리글 — http://chosun.gen.hs.kr
```

학부모 계정이 없으면 평가 계획을 볼 수 없는데 발급 방법이나 문의처가 없습니다.

누리집 주소가 `http`로 되어 있어 브라우저에 따라 경고가 뜹니다. 실제 서비스 주소를 확인해 주십시오.

### 자세를 지정하는 문구가 과하게 읽힐 수 있습니다

- 위치: 붙임 3 · 3번, 11번
- 대상: 1학년, 2학년, 3학년

원문

```
3. … 조용히 눈을 감고 손은 무릎 위에 놓고 대기합니다.
11. … 감독관의 지시 전까지 눈을 감은 상태로 두손은 머리 위에 올려 놓습니다.
```

고침

```
11. 시험 종료령이 울리면 즉시 필기구를 내려놓고, 답안지를 책상 위에 둔 채 회수가 끝날 때까지 답안지에 손을 대지 않고 대기합니다.
```

답안 수정을 막는다는 목적은 "필기구를 내려놓고 답안지에서 손을 뗀다"로 충분히 달성됩니다. 지금 문구는 학생 인권 관련 민원이 붙기 쉬운 형태입니다.

### 단원은 앞으로 가는데 쪽수는 뒤로 갑니다

- 위치: 붙임 2 · 3학년 컴퓨터구조
- 대상: 3학년

원문

```
3. 제어장치~4.기억장치(학습지 508~538, 250~302)
```

고침

```
3. 제어장치(학습지 250~302) ~ 4. 기억장치(학습지 508~538)
```

단원은 3에서 4로 가는데 쪽수는 508~538 다음이 250~302입니다. 서로 다른 자료라면 자료명을 밝혀 주시고, 아니면 출제 교사에게 확인이 필요합니다.

### 주어가 겹쳐 한 번에 읽히지 않는 문장이 있습니다

- 위치: 본문 · 3번 아래 줄
- 대상: 1학년, 2학년, 3학년

원문

```
- 최선을 다해 준비한 학생들의 수고와 노력이 의도하지 않은 실수로 한순간에 무너질 수 있는 것이 유의 사항을 지키지 않아 발생한다는 점을 인지하시어 자녀들이 시험 시행 규정을 준수할 수 있도록 지도 바랍니다.
```

고침

```
- 유의 사항을 지키지 않아 생긴 뜻하지 않은 실수로, 학생들이 최선을 다해 준비한 수고와 노력이 한순간에 무너질 수 있습니다. 이 점을 유념하시어 자녀들이 시험 시행 규정을 준수하도록 지도해 주시기 바랍니다.
```

`노력이`와 `것이`가 주어로 겹쳐 문장이 한 번에 읽히지 않습니다. 두 문장으로 나누면 뜻이 분명해집니다.

## 검토 방법

한컴오피스 없이 `python-hwpx`로 세 파일을 열어 본문·표·이미지를 뽑았습니다. 표는 셀 주소 단위로 펴서 시간표와 시험범위를 기계적으로 1:1 대조했고, 날짜와 요일은 달력으로 계산했습니다. 훈령 번호는 국가법령정보센터와 학교생활기록부 종합지원포털에서 확인했습니다. 지적은 일곱 가지 관점으로 나누어 병렬로 검토한 뒤 원문과 다시 대조해 걸러 냈습니다. 조판은 파일에 들어 있는 미리보기로 1쪽만 확인했으므로, 인쇄했을 때 페이지가 어디서 넘어가는지는 한글에서 한 번 봐 주십시오.
