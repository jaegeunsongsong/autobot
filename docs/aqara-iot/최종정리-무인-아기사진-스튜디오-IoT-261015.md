# 최종 정리: 무인 아기 사진 스튜디오 IoT 설비 (2026-10-15)

설계서 `IoT_261014.md`를 기준으로 검토·문답을 거쳐 확정된 내용의 전체 정리. 음성 파일 안내는 대표 결정으로 제외.

---

## 1. 확정된 운영 원칙 (대표 결정)

| 항목 | 결정 |
|---|---|
| 조명의 의미 | **불이 켜져 있으면 손님이 있는 것**으로 본다. 재실 센서는 넣지 않는다 |
| 소등 | **마감 + 15분에 메인홀 소등**. 이것은 "끝났다는 신호"이며, 손님이 벽 스위치로 다시 켜도 무관 |
| 비번 | **전날**에 다음 날 예약분 정기 비번을 만든다 |
| 예약 | **당일 예약 금지**(정리 일정·비번 전달 문제 예방). 전화로 빈 시간 문의 시 계좌이체로 받되, 전날 비번 생성에서 빠지지 않게 **네이버 예약에 대표가 대리 입력** |
| 음성 안내 | 제외 |
| 미니 UPS | 원래 제외 항목. 넣는다면 선택(5만 원 안쪽, 허브+공유기) |

## 2. 설비 구성 (설계서 그대로 + 확정 보완)

| 기기 | 수량 | 역할 | 확정 보완 |
|---|---|---|---|
| Hub M3 | 1 | 지그비 중심·로컬 자동화·IR·내장 스피커 | 유선 랜, 공유기와 1m 이상. **내장 스피커로 알림음·차임·사이렌(0원)** |
| 도어락 K100 | 1 | 정기 비번·일회용 비번·해제 알림 | 한국 서버 전용. 정기 비번은 FAQ상 **블루투스 설정** → 원격 가능 여부 10/16 확인 |
| 도어벨 G4 | 1 | 방문자 영상 통화 | **자동 응답 메시지** 설정("예약제 운영, 카카오 채널 문의") |
| CCTV E1 | 3 | 입구·메인홀 | 녹음 OFF · 화장실·수유실 화각 제외 · **팬틸트 회전 잠금** · **사람 감지 + 감지 시간대(20:30~08:30) + 이벤트 녹화** · 촬영 세트·탈의 구역은 화각에서 빼는 것 권장 |
| 벽 스위치 H2 | 3 | 메인홀 조명 | 전원복구 = ON. 업체에 **LED 드라이버 부하 정격·면조명 17개 돌입전류** 확인 |
| 스마트 전구 T2 | 14 | 레일 5700K·100% 고정 | 릴레이로 전원 차단 시 재접속 지연 가능. 유지한다면 디커플+상시전원 검토. 색온도 고정이면 일반 전구로 대체 가능(대표 판단) |
| 면조명 40W | 17 | 기본조명 | 견적에 **플리커프리·CRI 90 이상** 명기 권장 |
| FP300 | 1 | 화장실 조명 | 화장실 조명에 **물리 벽 스위치**도 있어야 함(허브 다운 대비) |
| 미니 스위치 T1 | 1 | 퇴실 버튼 | **2회 클릭**으로 변경, 길게 누름 = 도움 요청 푸시(선택) |
| 스마트 플러그 | 3 | 기기 전원·지그비 중계 | 인화기 **DNP DS620은 플러그 OK**(열전사). 본체 전원 스위치 상시 ON, 플러그 끄는 자동화는 자정 OFF만 |
| 작업실 문 | — | 손님 출입 차단 | 아카라 저가 도어락 없음(K100·U100만, 40만 원대). **기계식 보조키 1~3만** 또는 국산 디지털 보조키 5~10만 권장 |

항상 켜 두는 것: 현관등·미등·허브·공유기·CCTV·도어벨. 에어컨: 전원 차단 금지, 제조사 앱 스케줄(운영 후).

## 4. 비번 운영

| 항목 | 확정 |
|---|---|
| 생성 시점 | **전날**. 원격 생성이 안 되면 **마지막 팀 정리 방문 때** 생성(같은 "전날") |
| 유효 시간 | **시작 1시간 전 ~ 다음 팀 시작 15분 전**(마지막 팀 20:30). 조기 도착·연장 중 외출 재입장 해결 |
| 전달 | 생성 즉시 복사(재열람 불가) → 알림톡(솔라피 수동) 1회. 알림톡에 "입장 가능 시간" 포함 |
| 백업 1 | **일회용 비번**: 매장 인터넷·허브 무관하게 대표 폰에서 원격 생성, 1회·15분 |
| 백업 2 | **도어벨 G4 영상 통화**로 확인 후 일회용 비번을 말로 전달 |
| 백업 3 | **1층 부모님 지문 등록**(최종 백업) |
| 취소 | 비번 삭제 + B 칸 OFF |
| 동기화 | 생성 후 "동기화 완료" 확인 절차 |

## 6. 0원 설정·운영 항목

- 아카라 계정 **2단계 인증**, 남편 **관리자 권한**(일반 구성원은 비번 생성 불가 가능성)
- 전구·H2 **전원복귀 = ON**, 모든 기기 펌웨어 최신화 후 **자동 업데이트 OFF**
- 공유기 2.4GHz 채널 **1 또는 6 고정**(자동 OFF), AP 격리 OFF, **손님 Wi-Fi는 5GHz만**(카메라 3대가 2.4GHz 사용)
- 플러그 3개는 미니 스위치·FP300·(누수 센서) 근처에 배치(중계)
- **050 안심번호 또는 카카오 채널 전화**를 안내판에
- **119용 주소·층 안내판**, 구급상자, 건물 비상조명·유도등 확인, 급탕 온도 상한
- 도어 클로저 힘 조절, 안내 "유모차를 먼저 들이고 문을 닫아 주세요", K100 **내부 강제잠금 OFF**
- 9V 건전지 **1층 가게 + 대표 차** 2곳
- 매일 B 입력 후 **켜진 칸 스크린샷**을 같은 카톡방에

## 7. 10/16 설치 당일 확인 (우선순위)

1. K100 정기 비번을 **집(LTE)에서 생성·동기화**할 수 있나
2. 계정 서버 지역 **대한민국**, 모든 기기 KC 정발
3. **공유기 인터넷선 뽑고** A1·A2·A5·B 동작
4. A3 4시간 30분 입력 가능·허브 재부팅 후 유지
5. K100 "비번으로 해제" 구분, "문 열림 지속" 알림 유무
6. K100 **9V 비상전원 단자 위치**, 내부 강제잠금 OFF, 자동잠금 ON, 저전압 알림 ON
7. H2 모드·전원복귀 ON, 벽 버튼으로 전구 14개 2초 내 반응
8. 중성선·박스 깊이·면조명 부하 정격(업체)
9. 공유기 2.4GHz 채널 고정, 허브 유선, Zigbee 채널 겹침 확인
10. 플러그 위치·센서 신호 세기
11. FP300 화장실 5분 정지 테스트, **화장실 물리 스위치 유무**
12. E1 microSD(용량·내구성), 녹음 OFF, 회전 잠금, 사람 감지·시간대·이벤트 녹화
13. G4 전원·차임 위치·microSD, 자동 응답 메시지, 1층에서 호출 테스트
14. 남편 계정 권한, 일회용 비번 생성 테스트
15. 허브 경비 모드 시간표, 펌웨어 자동 업데이트 OFF

## 8. 법적으로 챙길 것 (개인정보보호법 제25조)

- 설치 사유 "시설 안전 및 범죄 예방" 명시
- 화장실 등 설치 금지, 수유실 화각 제외, 회전 카메라로 비추지 않을 것
- **안내판**: 설치 목적·장소, 촬영 범위·시간, 관리책임자 연락처, 수탁자(솔라피) → 입구·메인홀·**현관 밖(도어벨)**
- **녹음 금지**, 임의 조작 금지
- **운영·관리 방침** 문서(목적, 대수·위치, 보관기간, 접근권한자, 파기, 열람 절차). 보관기간은 실제 용량에 맞게(2K 3대 상시 512GB ≈ 16~20일 추정 → 이벤트 녹화·14일 권장)
- 예약자 전화번호는 예약 이행 목적, 처리방침에 수탁자 기재
