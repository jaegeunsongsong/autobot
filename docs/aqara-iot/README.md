## 1. 핵심 멘탈 모델 (이것만 기억하면 대부분의 실수를 걸러냄)

1. **"한 계정 = 한 서버 지역"**. 정발품은 대한민국 서버, 알리 내수판은 중국 본토 서버. 섞으면 한쪽이 등록 불가. K100 도어락·카메라 SmartThings 연동은 한국 서버 전용. 중국 서버는 구글홈·알렉사 연동 불가. 바꾸려면 기기 삭제 후 재등록.
2. **아카라 허브는 아카라 Zigbee 기기 전용**. 타사 Zigbee는 안 붙음. 타사와 섞으려면 Matter(Thread/Wi-Fi) 또는 Home Assistant + 범용 동글(Z2M/ZHA).
3. **라우터가 메시를 만든다**. 상시전원(플러그, 중성선 있는 스위치, 릴레이)만 중계. 배터리 센서·중성선 없는 스위치는 중계 안 함. 센서 8~10개당 라우터 1개. 꺼질 수 있는 스마트전구는 라우터로 쓰지 않음.
4. **한국 스위치 박스는 중성선이 없다고 가정**. 중성선 없는 모델은 LED 최소부하(약 5W) 미달 시 잔광·깜빡임. 한국형 WS-KRC 또는 H2(중성선 유무 모두 지원) 검토. EU H1(86×86mm, 매립 깊이 30mm)은 국산 박스와 규격 불일치 가능.
5. **Matter 브리지는 "기본 기능"만 넘긴다**. 버튼 멀티클릭, 큐브 제스처, FP2 존, IR 다중 에어컨, 카메라 영상은 축소·누락. 고급 자동화는 Aqara 앱(또는 HA)에 두고, SmartThings·구글홈·애플홈은 "보기/제어/음성"용으로.
6. **인터넷 끊겨도 돌아야 할 자동화는 로컬 조건만**(센서·시간). 지오펜싱·날씨·푸시는 클라우드. WAN 뽑고 테스트.
7. **보일러·월패드는 아카라 영역이 아니다**. 보일러는 제조사 Wi-Fi 조절기 → 제조사 앱/SmartThings. 월패드는 삼성 스마트아파트(단지별) 또는 HA RS485(비공식). 아카라 W400(2026-09 국내 출시, 바닥난방 연동 표방)은 호환 확인 후 판단.
8. **2.4GHz 혼잡 대응은 공유기 쪽에서**. 아카라 허브는 Zigbee 채널 변경이 사실상 불가 → 공유기 2.4GHz를 1 또는 6 고정, 자동 채널 OFF. 허브는 공유기·USB 3.0에서 1~2m 이상.
9. **펌웨어 자동 업데이트는 끈다**. 2025년 M3 4.5.30 사태처럼 Matter 자녀기기 장애 전례. 1~2주 포럼 반응 후 수동 적용.
10. **음성은 Siri·구글·빅스비만 기대**. 클로바·카카오홈·NUGU는 종료/쇠퇴. 빅스비는 Matter 브리지 → SmartThings 경유.

## 2. 사용자 계획을 검토할 때 먼저 물을 것

- **주거 형태**: 아파트(준공 2022-07 전후? 월패드 제조사? 삼성 스마트아파트 지원 단지? 지역난방?) / 빌라·단독(가스보일러 제조사?)
- **폰·생태계**: 아이폰(→ 애플홈 중심) / 갤럭시(→ SmartThings 중심) / HA 운용 의향
- **구매 경로**: 정발(아카라라이프·삼성닷컴·컬리·11번가 본사) / 알리 직구 / 혼합 → 서버 지역 결정
- **규모**: 센서 수, 상시전원 기기 수, 집 평수·층수 → 허브 선택(M100 20대 한도 / M3 127대) 및 라우터 배치
- **스위치**: 교체하려는 스위치의 구수, 중성선 유무(차단기 내리고 박스 열어 확인), 등기구 종류(LED W수), 박스 깊이
- **반드시 돌아야 하는 자동화**: 현관등·누수·보안 → 로컬 가능한지
- **공유기**: 2.4GHz 채널 고정 가능? AP 격리 OFF? IPv6/mDNS(M3 Matter 요건)?

## 3. 2026년 기준 추천 구성(기본안)

- **허브**: M3 1대(Zigbee+Thread+Matter 컨트롤러/브리지+IR+PoE). 소규모 입문은 M100. Zigbee만이면 M2.
- **라우터 겸 기기**: 스마트 플러그 SP-EUC01(한국 콘센트 직접 사용, 10A 한도), 중성선 있는 스위치가 있으면 그것.
- **센서**: 도어 T1(현관처럼 출입 잦은 곳은 P2/CR123A), 모션 P1 또는 P2, 존재감지 FP300(2026-01 국내 출시) 또는 FP2(Wi-Fi), 온습도 T1(욕실 비권장), 누수 T1.
- **스위치**: 한국형 WS-KRC(중성선 불필요) 또는 H2. H1 EU 직구는 박스 규격·KC·서버 문제 3중 확인.
- **도어락**: 한국 현관 규격은 K100(한국 서버 전용). U200/U300은 국내 미출시·규격 불일치.
- **연동**: 아이폰 → 애플홈(홈허브 있어야 원격/자동화). 갤럭시 → M3 Matter 브리지 → SmartThings(ST 허브 역할 기기 필요) + Advanced Matter Bridging으로 씬 동기화. 둘 다 → 멀티어드민 가능하나 자동화는 한 곳에 집중.
- **프라이버시·로컬 우선** → HA(허브→HomeKit Controller 또는 Matter 브리지, 혹은 범용 동글+Z2M).

## 4. 자주 틀리는 전제 (첨언 포인트)

| 사용자가 흔히 말하는 것 | 실제 |
|---|---|
| "알리에서 싸게 사서 정발 허브에 붙이면 되지" | 서버 지역이 달라 등록 불가. 모델코드 접미사(KR/CN/EU) 확인 |
| "스마트싱스 허브에 아카라 센서 직접 붙이면 되지" | 커뮤니티 Edge 드라이버 의존, 수시 오프라인 보고. 안정 경로는 아카라 허브→Matter→ST |
| "매터로 넘기면 아카라 앱 안 써도 되지" | 멀티클릭·FP2 존·IR 다중 에어컨 등 손실. 고급 설정은 아카라 앱 필수 |
| "센서 30개 사서 허브 하나에" | 라우터 없으면 직접 연결 한도(⚠️ 32 추정)에서 오프라인 연쇄 |
| "스위치는 그냥 갈아끼우면 되지" | 중성선 확인, LED 최소부하, 박스 깊이, 86mm vs 국산 세로형 규격. 동종 교체는 경미한 공사 범위로 보이나 배선 변경은 공사업자 |
| "보일러도 아카라 온도조절기로" | 국내 보일러는 제조사 전용 통신. W400 호환 확인 전까지는 제조사 Wi-Fi 조절기가 정답 |
| "클로바/카카오로 음성 제어" | 종료·쇠퇴. Siri/구글/빅스비만 |
| "FP2 천장에 달면 방 전체 커버" | 천장은 반경 ~2m·낙상 전용. 벽면 2m 이하, 선풍기·커튼·TV 간섭원 존 설정 |
| "현관 철문에 도어센서 본체 붙이기" | 금속면 신호 감쇠. 본체는 문틀, 자석은 문짝, 간격 22mm 미만 |

## 5. 미확인·추가 조사 필요 항목(통합)

- M3의 허브 직접 연결 엔드 디바이스 정확한 한도, 최신 펌웨어의 Zigbee 채널 수동 변경 가능 여부
- Edge Mode 토글 공식 설명, 허브 2대 걸친 자동화의 로컬 실행 여부
- Matter 브리지로 노출되지 않는 기기/속성 공식 목록(진동센서·도어락 포함)
- 아카라 계정 2FA 공식 지원·강제 여부
- 아카라 W400의 국내 보일러 연동 방식·호환 목록
- 한국형 스위치 WS-KRC 정확한 치수, 3구 존재 여부, H2 가로형 국내 출시
- 큐브·누수·진동·W100·FP1E·H2·커튼드라이버 국내 정발/가격, 연기·가스 감지기 국내 인증
- 카카오홈 종료일 공식 공지, 클로바 스마트홈 종료 여부, 직방 도어락-ST 공식 연동
- 2026년 한전 주택용 요금표, 시스템에어컨 서드파티 연동, 한국 방화문 실설치 후기
