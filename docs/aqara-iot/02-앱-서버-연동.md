# 아카라(Aqara) 한국 실사용 가이드: 앱·서버·자동화·생태계 연동 (조사일 2026-10-14)

> 조사 방법 메모: 웹페이지 직접 열기가 네트워크 정책으로 차단되어, 모든 내용은 검색 결과 요약 기준. 원문을 직접 읽지 못한 항목은 "⚠️ 확인 필요".

## 1. Aqara Home 앱의 서버(계정 지역) 선택

**한국 서버는 실제로 존재합니다.**
- Aqara 개발자 문서의 지역 비교표에 한국(KR)이 독립 리전으로 등재, 접속 서버는 coap-kr.aqara.com / rpc-kr.aqara.com. → https://opendoc.aqara.com/en/docs/SDKDevelopment/AndroidDevelopmentGuide/RegionComparisonTable.html
- Aqara EU 개인정보처리방침: 중국, 미국, 싱가포르, 한국, 러시아, 독일에 데이터센터 운영. → https://eu.aqara.com/en-eu/pages/privacy-policy (⚠️ 미국 정책 페이지에는 한국이 빠져 있음)
- 아카라라이프(한국 총판) G3 매뉴얼 FAQ: 클라우드 서버는 한국(AWS). 카메라를 미국 국가로 등록하면 미국 리전에 저장. → https://aqaralife.gitbook.io/manual/camera/g3
- 구글홈 연동 가이드: 로그인 화면에서 "계정 영역 → 대한민국". → https://aqaralife.gitbook.io/manual/platform/googlehome/connecting

**원칙: 기기를 산 곳(유통 리전)에 맞춘다**
- 정발 제품 → 대한민국 서버. 스마트 도어락 K100은 한국 서버 전용, 카메라 SmartThings 연동도 한국 서버 필수. → https://aqaralife.gitbook.io/manual/platform/smartthings , https://www.clien.net/service/board/cm_iot/18431661
- 중국 내수판 직구 → 중국 본토 서버에서만 등록되는 경우가 대부분. → https://www.clien.net/service/board/cm_iot/18431661 , https://namu.wiki/w/Aqara
- 중국판 M100 허브는 중국 본토 서버만. → https://forum.aqara.com/t/cant-switch-aqara-m100-from-usa-to-china-region/33870

**잘못 고르면**
- 리전 미등록 모델은 기기 추가 불가(리전 락). → https://homekitnews.com/2019/12/17/aqara-hub-101/
- 중국 본토 서버 → 구글홈·알렉사 연동 불가. → https://homesmart.sg/setting-up/ , https://forum.lowyat.net/topic/3554748/+8860
- 알렉사 스킬 리전 불일치 → 기기 안 보임. → https://scos.co.uk/troubleshooting/aqara/aqara-not-compatible-with-alexa/
- HomeKit은 서버 무관 로컬 동작. 중국판 허브도 애플홈 가능. (구형 후기: 로그인 없는 홈킷 모드에서 M2 펌웨어 업데이트는 중국 계정 로그인 필요 ⚠️) → https://www.sejunine.com/entry/아카라-스마트홈-키트-M2-허브
- 지연: 한국 서버 정발 제품은 문제 적음. 중국 서버는 국제 구간 → 느릴 수 있음(수치 ⚠️).

**나중에 바꿀 수 있나?**
- 지역 변경 시 기존 리전 기기가 보이지 않음 → 삭제 후 재등록. → https://forum.aqara.com/t/cant-switch-aqara-m100-from-usa-to-china-region/33870
- 중국판·한국판 혼용 → 리전별 계정 따로, 로그인/로그아웃 반복. → https://community.home-assistant.io/t/aqara-new-people-presence-sensor-fp2/545374?page=15
- 결론: 정발 제품 + 대한민국 서버로 통일. 서로 다른 리전 기기는 한 자동화에 못 넣음.

## 2. 페어링 흐름과 흔한 실패

**허브 추가**: 앱 "+" → 모델 선택 → Wi-Fi 설정. M3는 네트워크 설정 시 2차 인증. M3 Matter는 IPv6(ULA) 지원 공유기 필요. → https://aqaralife.gitbook.io/manual , https://aqaralife.gitbook.io/manual/smarthub/m2 , https://aqaralife.shop/product/아카라-스마트-허브-m3/216/

**Zigbee 자식 기기**: 허브 선택 → 하위 기기 추가 → 리셋 버튼 길게. 아카라 허브는 아카라 Zigbee 기기 전용(제3자 불가), M3 최대 127대. → https://eu.aqara.com/products/aqara-smart-hub-m3

**Thread/Matter 기기(P2, FP300 등)**: Thread 보더라우터(M3·M100) 필요, Matter QR 스캔. 타 플랫폼으로 넘길 때 "페어링 코드 생성"(15분 유효). → https://forum.aqara.com/t/cannot-pair-door-and-window-sensor-p2-to-aqara-hub-m3-via-matter/5481

**실패 체크리스트**
1. 폰·허브 같은 2.4GHz Wi-Fi, AP 격리 해제, mDNS 허용, 5GHz 임시 비활성화. → https://aqaralife.gitbook.io/academy/iot_rudimentary/basic/01/7
2. 반복 실패 → iOS 재부팅, 허브 초기화(M2: 버튼 10회 / M3: 리셋 10초), 3분 후 HomeKit 코드 수동 입력. → https://aqaralife.gitbook.io/manual/smarthub/m2
3. "이미 추가된 장치" → 애플홈/아카라홈 이전 등록 삭제.
4. Zigbee 간섭 → 허브 채널 확인(허브 여러 대면 채널 다르게), 공유기와 거리.
5. Thread 실패 → 공장 초기화 후 재시도, iOS 키체인 잔존 삭제, VPN 끄기, BR 가까이. → https://community.smartthings.com/t/aqara-matter-door-and-window-sensor-p2-thread-pairing-fails/276695
6. Matter 기기는 먼저 아카라 홈에 붙여 펌웨어(Matter 1.4) 올린 뒤 초기화·재페어링. → https://privatehomelab.com/aqara-door-window-sensor-p2-matter-thread-home-assistant/

## 6. 펌웨어·오프라인·프라이버시

- 펌웨어: 앱 → 기기 → 세부 정보. 같은 Wi-Fi. 허브 이관 전 최신화. M3 노란 느린 점멸 = 업그레이드. → https://www.aqara.com/kr/support/hub-m2

## 요약 권고
1. 정발 제품 + 대한민국 서버. 직구는 중국 서버 전용 계정 별도, 구글/알렉사/ST 클라우드 연동 불가.
2. 허브는 M3(또는 M100/M200). 공유기 IPv6/mDNS 확인.
3. 삼성 가전·빅스비 → Matter 브리지 → SmartThings(ST 허브 기기 필요) + Advanced Bridging.
4. 클라우드 의존·프라이버시 걱정 → HomeKit 또는 HA로 로컬화.
5. 클로바·카카오홈 직접 연동 기대 금지.
