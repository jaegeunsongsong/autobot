# 2026학년도 2학기 통계독서탐구 수행평가 (2학년 확률과 통계)

평가 기준표(11월, 100점, 반영 30%, 성취기준 [12확통03-01], [12확통03-05])를 그대로 두고, 학생과 교사가 할 일을 셋으로 줄인 운영 자료다.
학생은 활동지 한 장(앞뒤)을 채우고 그 내용을 PPT 4장에 옮겨 2분 발표한다. 교사는 활동지의 칸을 체크하고 발표에서는 평가 요소 4만 본다.

## 파일

| 파일 | 내용 | 대상 |
| --- | --- | --- |
| `운영안.md` | 3단계 흐름, 평가 요소와 활동지 칸의 대응, 채점 절차와 요소 4 판정표, 발표 운영, AI 규정 적용, 예상 상황, 11월 일정 | 교사 |
| `안내문-활동지.md` | 안내문, 활동지, 작성 예시의 본문 텍스트. 학교 양식(한글)에 복사해 쓰기 좋다 | 교사 → 학생 |
| `인쇄용.html` | 안내문 2쪽, 활동지 2쪽(앞뒤), 작성 예시 1쪽, 교사용 채점표 1쪽. 브라우저에서 열어 A4로 인쇄 | 학생 배부용, 교사 채점용 |
| `발표틀.pptx` | 학생에게 나눠 주는 4장짜리 PPT 틀. 대괄호 안의 안내 글만 바꾸면 된다. 슬라이드 노트에 장면별 시간 배분 | 학생 |

## 쓰는 순서

1. `운영안.md`를 읽고 날짜 세 개(안내일, 제출일, 발표일)를 정한다.
2. `인쇄용.html`을 열어 안내문의 날짜 빈칸을 채운 뒤 A4로 인쇄한다. 학생 1인당 안내문 1장(앞뒤), 활동지 1장(앞뒤), 예시 1장.
3. `발표틀.pptx`를 학급 과제함에 올린다.
4. 제출 뒤 활동지로 요소 1~3을 채점하고, 발표 날 채점표(인쇄용 6쪽)에 요소 4만 적는다.

## 작성 예시의 숫자

작성 예시(출생아 수 2020~2025년, 혼인 건수)는 국가데이터처(옛 통계청) 인구동향조사·혼인이혼통계 발표치를 만 명(만 건) 단위로 반올림한 것이다. 2025년 출생아 수는 2026년 8월 확정치(25만 4천 명) 기준이다. 학생이 KOSIS에서 다시 확인하도록 안내문에 적어 두었다.
