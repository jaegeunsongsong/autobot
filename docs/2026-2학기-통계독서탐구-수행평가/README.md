# 2026학년도 2학기 통계독서탐구 수행평가 (2학년 확률과 통계)

평가 기준표(11월, 100점, 반영 30%, 성취기준 [12확통03-01], [12확통03-05])를 그대로 두고, 학생과 교사가 할 일을 셋으로 줄인 운영 자료다.
학생은 활동지 한 장(앞뒤)을 채우고 그 내용을 PPT 4장에 옮겨 2분 발표한다. 교사는 활동지의 칸을 체크하고 발표에서는 평가 요소 4만 본다.
평가 요소 4개 = 활동지 4칸 = PPT 4장 = 발표 4부분으로 한 줄기로 이어지게 짰다. 결론은 '통계가 보여 준 것 → 통계 분석 → 결론' 세 부분으로 쓴다.

## 쓰는 순서

1. `운영안.md`를 읽고 날짜 세 개(안내일, 제출일, 발표일)를 정한다.
2. `인쇄용.html`을 열어 안내문의 날짜 빈칸을 채운 뒤 A4로 인쇄한다. 학생 1인당 안내문 3쪽, 활동지 1장(앞뒤), 작성 예시 A 1장(앞뒤). 예시 B와 발표 예시는 선택이며 화면으로 보여 줘도 된다.
3. 보고서 쓰는 날 1주 전에 `사전안내.html`을 주고 준비를 시킨다. 보고서 쓰는 날 `보고서-양식.html`, `보고서-예시.html`의 한 편, `통계사이트-모음.html`을 준다. 발표 준비 때 `발표틀.pptx`와 `발표예시.pptx`를 학급 과제함에 올린다.
4. 제출 뒤 활동지로 요소 1~3을 채점하고, 발표 날 채점표(인쇄용 10쪽)에 요소 4만 적는다.

## 작성 예시의 숫자

- 예시 A(출생아 수 2020~2025년, 혼인 건수): 국가데이터처(옛 통계청) 인구동향조사·혼인이혼통계 발표치를 만 명(만 건) 단위로 반올림했다. 2025년 출생아 수는 2026년 8월 확정치(25만 4천 명) 기준이다.
- 예시 B(청소년 스마트폰 과의존 위험군 비율 2022~2024년, 유아·아동 25.9%, 전체 22.9%): 과학기술정보통신부·한국지능정보사회진흥원 「2024 스마트폰 과의존 실태조사」(2025년 3월 발표).
- 진로별 예시 1(간호): 질병관리청 「청소년건강행태조사」(중1~고3, 800개교 약 6만 명 표본) 주 5일 이상 아침식사 결식률 2021~2025년(남·여), 2024년 주관적 수면충족률. 결론의 효과 통계는 농촌진흥청·다음 설문(2002. 7. 발표, 대학 1·2학년 3,612명 자기보고): 고교 때 아침을 매일 먹은 응답자 수능 평균 294점, 주 2일 이하 275점(400점 만점), 내신 평균 3.7 대 4.4등급. 같은 방향의 분석으로 한국가정의학회지(2019)의 2017년 청소년건강행태조사 논문을 인용.
- 진로별 예시 2(공학): 국토교통부 「자동차등록현황보고」 연말 전기차 누적 등록 대수 2020~2025년(e-나라지표), 그해 증가 대수는 누적의 차이로 계산.
- 진로별 예시 3(교육): 교육부·한국교육개발원 「교육기본통계」 초·중·고 다문화 학생 수와 비율 2021~2025년, 초·중·고 전체 학생 수 2021~2025년(2025년 501.5만 명 = 초 234.5 + 중 137.0 + 고 129.9).
- 모든 예시에 학생이 직접 확인하도록 적어 두었다. 2023년 다문화 학생 수(18.1만 명)와 2021~2023년 초·중·고 학생 수는 발표된 비율(3.0·3.2·3.5%)과 맞는 값이지만 교육통계연보에서 확인이 필요하다.
