# 사전 설명 단계 진행안 (교사용)

보고서 쓰는 날(10월 30일) 1주 전, 수업 중 40분. 전체 자료를 한 번 보여 주고 30일까지 준비할 것을 분명히 한다. 학생이 이 시간에 알아야 할 것은 셋이다. ① 무엇을 만드는지(완성본) ② 점수가 어디서 나는지 ③ 30일까지 무엇을 해 오는지. 인쇄용은 `사전설명-진행안.html`.

## 수업 전 교사 준비

- 화면에 띄울 파일을 순서대로 열어 둔다: 인쇄용.html(1쪽) → 발표-체크리스트.html → 보고서-예시.html → 발표예시-간호.pptx → 보고서-양식.html → 통계사이트-모음.html → 사전안내.html
- 사전안내.html을 학생 수만큼 인쇄한다(보고서 양식은 30일에 준다). 출구 쪽지는 아래 양식을 잘라 쓰거나 공책에 쓰게 한다
- 학교 망에서 index.go.kr, kosis.kr이 열리는지 미리 확인한다. 막히면 시연 대신 통계사이트-모음.html의 "얻는 길" 열을 읽어 준다
- 도서관에 통계·데이터 책을 모아 달라고 부탁한다(안내문 3쪽 목록)

## 진행 (40분)

### 1. 도입: 한 문장과 일정 (3분) · 화면: 인쇄용.html 1쪽

"어떤 통계로 어떤 주장을 할지 정하고, 실제 통계로 표 2개와 그래프 1개를 만들어 보고서 2쪽에 쓰고, PPT 4장으로 발표합니다. 100점, 반영 30%. 보고서는 10월 30일 수업 시간에 씁니다. 오늘은 완성본을 보고, 그날까지 무엇을 준비할지 정합니다."

### 2. 점수가 어디서 나는가 (5분) · 화면: 발표-체크리스트.html

네 가지 20·30·30·20. 발표에서 ①~⑩에 ○·×를 매긴다: 도서·저자·책에서 얻은 조언 / 출처·전수냐 표본이냐·가공 전후·그래프 / 숫자·의견·근거. "이 열 가지가 보고서의 칸이고, PPT 4장이고, 발표 순서입니다. 열 가지만 빠뜨리지 않으면 됩니다." 어느 반이든 같은 체크리스트로 채점한다고 말한다.

### 3. 완성본 먼저: 보고서 예시 (10분) · 화면: 보고서-예시.html 1~2쪽(간호)

위에서부터 짚는다. 제목은 키워드만(문장 아님) → 1번은 쓸 통계 + 주장 한 문장, 진로에서 출발 → 2번 책은 조언("느낌 대신 숫자로 보라 → 5년치를 나란히 놓았다") → 3번 표 1은 원자료 그대로(…은 안 옮긴 칸)에 출처·표본 표시, 표 2는 필요한 줄만 골라 다시 만든 것, 그래프는 표 2를 꺾은선으로, 세로축 0 → 4번은 숫자의 움직임만("39.1% → 45.3%, +6.2%p") → 5번은 통계를 근거로 한 내 의견 → 참고 자료는 링크만. "칸마다 4줄, 음슴체. 이것이 만점이고 더 길게 쓰지 않아도 됩니다." 공학·교육 예시는 1쪽씩 30초만 넘겨 보여 준다.

### 4. 보고서가 PPT와 발표가 된다 (5분) · 화면: 발표예시-간호.pptx 4장

보고서 1·2번 → 1장, 3번 → 2·3장, 4·5번 → 4장. "PPT는 점수가 없고 발표 순서를 잡아 주는 화면입니다. 발표틀.pptx의 대괄호 안만 바꾸면 됩니다."

### 5. 빈 양식과 "그날 가져올 것" (5분) · 화면: 보고서-양식.html

"30일에 이 2쪽을 받아 그 자리에서 씁니다. 글은 칸마다 4줄이라 그날 쓰면 됩니다. 그러나 표 1(원자료 캡처·출력), 표 2 초안, 그래프, 링크는 그날 못 만듭니다. 집에서 준비해 와서 붙이거나 옮겨 적습니다." 양식의 출처·전수/표본 칸을 가리키며 "이 한 줄이 2번 점수의 절반"이라고 말한다.

### 6. 자료는 어디서: 3분 시연 (8분) · 화면: 통계사이트-모음.html → 브라우저

실제로 한 번 한다. index.go.kr에서 "자동차 등록현황" 검색 → 표 → 연료별 → 화면 캡처. 또는 kosis.kr에서 "아침식사 결식률" 검색 → 표 → 통계설명자료 → 조사 방법(표본) 확인 → 다운로드. "연도별 숫자가 3개 이상 있는 표면 됩니다. 기관 이름·조사 이름·주소를 적어 두세요. 표 위의 통계설명자료에서 전수조사인지 표본조사인지 봅니다." 진로별 예는 사전안내의 누리집 표를 가리킨다.

### 7. 책과 규칙 (4분) · 화면: 인쇄용.html 3쪽 책 목록 → 사전안내.html "꼭 지킬 것"

"책은 통계 활동에 조언을 얻는 참고입니다. 주장을 책에서 찾지 않습니다. 도서관의 통계·데이터 책 한 장(章)이면 되고, 도서명·저자와 어떤 조언을 얻었는지 한두 문장을 씁니다." 규칙 셋: 출처 있는 실제 통계만(뉴스 그래프 캡처만 ×, 출처 "네이버" ×) · AI는 검색·요약에만(표·그래프·해석·결론을 AI로 쓰면 그 요소 최하점, 발표 뒤 질문 1개) · 칸마다 4줄, 제목은 키워드.

### 8. 준비물 확인과 출구 쪽지 (5분) · 화면: 사전안내.html 배부

여섯 가지를 같이 읽고 날짜를 확인한다. "수업 끝나기 전에 쪽지에 주장 한 문장(또는 아직 모름), 쓸 통계(또는 아직 모름), 책(있으면)을 적어 냅니다." 걷어서 "모름"인 학생을 파악한다.

## 이 단계 뒤 1주일 동안 교사가 할 일

- 쪽지에서 "모름"인 학생은 다음 수업에 2분씩 본다. 진로를 묻고 진로별 예시(간호·공학·교육) 중 가까운 것을 그대로 따라 하게 한다. 같은 자료로 다른 연도·다른 지역을 봐도 된다
- 3~4일 뒤 "표 1 캡처한 사람 손 들어" 한 번. 안 된 학생에게는 e-나라지표(index.go.kr)를 권한다. 처음 쓰기에 가장 쉽다
- 30일 당일: 보고서 양식 2쪽, 통계사이트-모음, 작성 예시 1편(또는 화면)을 주고 50분 안에 쓰게 한다. 글은 4줄씩이라 시간이 모자라지 않는다
- 발표 전: 발표틀.pptx와 발표예시.pptx를 학급 과제함에 올린다. 발표 날 채점 교사에게 발표-체크리스트.html을 반마다 한 장 준다

## 20분 압축판

1 도입(3분) → 3 보고서 예시 간호 편만(8분) → 5 빈 양식과 그날 가져올 것(4분) → 8 사전안내 배부와 출구 쪽지(5분). 6 시연은 사전안내의 누리집 표를 읽어 주는 것으로 대신하고, 2·4·7은 사전안내의 "꼭 지킬 것"과 "일정과 점수"로 대신한다.

## 자주 나오는 질문과 답

| 질문 | 답 |
|---|---|
| 책을 꼭 다 읽어야 하나 | 아니다. 통계 활동에 조언이 될 한 장(章)이면 된다. 주장과 책 주제가 달라도 된다 |
| 통계가 내 주장과 반대로 나오면 | 주장을 통계에 맞게 바꾼다. 그것이 "통계로 주장을 정하는" 것이다 |
| 자료가 2개 있어야 하나 | 1개로 충분하다. 5번 결론의 근거로 다른 숫자를 하나 더 쓰면 좋다 |
| 몇 년치를 쓰나 | 3~6년. 너무 길면 표가 복잡해진다 |
| 비율(%) 자료만 있으면 | 된다. 막대그래프로 그린다 |
| 손으로 써야 하나 | 보고서는 손으로 쓴다. 표 1과 그래프는 출력물을 붙여도 된다. 엑셀 그래프도 세로축 0·제목·단위만 지키면 된다 |
| 전수인지 표본인지 모르겠으면 | KOSIS 표 위의 통계설명자료 → 조사 방법. "전국 모든 ~을 집계"면 전수, "~명을 뽑아 조사"면 표본 |
| AI로 자료를 찾아도 되나 | 검색어 고르기와 전문 자료 요약은 된다. 표·그래프·해석·결론은 직접 쓴다. 발표 뒤 질문에 답할 수 있어야 한다 |
| 친구와 같은 자료를 써도 되나 | 된다. 주장·해석·결론은 각자 쓴다 |
| 외국 자료도 되나 | 출처와 링크가 있으면 된다. 가능하면 국내 통계를 권한다 |

## 이 시간에 꼭 남겨야 할 세 문장

- **출발점:** 주장은 통계로 정한다. 하고 싶은 주장이 있으면 받칠 통계를, 눈에 띈 통계가 있으면 거기서 할 주장을 생각해 온다. 책은 통계 활동에 조언을 얻는 참고다.
- **만들 것:** 표 1(원자료 그대로, 출처·전수/표본) → 표 2(필요한 줄만 골라 다시) → 그래프(세로축 0, 제목·단위). 이 셋은 집에서 준비해 온다.
- **쓸 것:** 칸마다 핵심만 4줄, 제목은 키워드. 해석은 숫자의 움직임, 결론은 통계를 근거로 한 내 의견. 발표에서 열 가지를 다 말한다.
