전체 자료를 한 번 보여 주고 30일까지 준비할 것을 분명히 하는 시간입니다. 학생이 알아야 할 것은 셋: ① 완성본이 무엇인지 ② 점수가 어디서 나는지 ③ 30일까지 무엇을 해 오는지.

  • 화면에 띄울 파일을 순서대로 열어 둔다: 인쇄용.html(1쪽) → 발표-체크리스트.html → 보고서-예시.html → 발표예시-간호.pptx → 보고서-양식.html → 통계사이트-모음.html → 사전안내.html
  • 사전안내.html을 학생 수만큼 인쇄한다(보고서 양식은 30일에 준다). 출구 쪽지는 아래 양식을 잘라 쓰거나 공책에 쓰게 한다
  • 학교 망에서 index.go.kr, kosis.kr이 열리는지 미리 확인한다. 막히면 시연 대신 통계사이트-모음.html의 "얻는 길" 열을 읽어 준다
  • 도서관에 통계·데이터 책을 모아 달라고 부탁한다(안내문 3쪽 목록)

310분완성본 먼저: 보고서 예시
화면: 보고서-예시.html 1~2쪽(간호)
위에서부터 짚는다. 제목은 키워드만(문장 아님) → 1번은 쓸 통계 + 주장 한 문장, 진로에서 출발 → 2번 책은 조언("느낌 대신 숫자로 보라 → 5년치를 나란히 놓았다") → 3번 표 1은 원자료 그대로(…은 안 옮긴 칸)에 출처·표본 표시, 표 2는 필요한 줄만 골라 다시 만든 것, 그래프는 표 2를 꺾은선으로, 세로축 0 → 4번은 숫자의 움직임만("39.1% → 45.3%, +6.2%p") → 5번은 통계를 근거로 한 내 의견 → 참고 자료는 링크만. "칸마다 4줄, 음슴체. 이것이 만점이고 더 길게 쓰지 않아도 됩니다." 공학·교육 예시는 1쪽씩 30초만 넘겨 보여 준다.

  • 30일 당일: 보고서 양식 2쪽, 통계사이트-모음, 작성 예시 1편(또는 화면)을 주고 50분 안에 쓰게 한다. 글은 4줄씩이라 시간이 모자라지 않는다
  • 발표 전: 발표틀.pptx와 발표예시.pptx를 학급 과제함에 올린다. 발표 날 채점 교사에게 발표-체크리스트.html을 반마다 한 장 준다

질문답
책을 꼭 다 읽어야 하나아니다. 통계 활동에 조언이 될 한 장(章)이면 된다. 주장과 책 주제가 달라도 된다
통계가 내 주장과 반대로 나오면주장을 통계에 맞게 바꾼다. 그것이 "통계로 주장을 정하는" 것이다
자료가 2개 있어야 하나1개로 충분하다. 5번 결론의 근거로 다른 숫자를 하나 더 쓰면 좋다
몇 년치를 쓰나3~6년. 너무 길면 표가 복잡해진다
비율(%) 자료만 있으면된다. 막대그래프로 그린다
손으로 써야 하나보고서는 손으로 쓴다. 표 1과 그래프는 출력물을 붙여도 된다. 엑셀 그래프도 세로축 0·제목·단위만 지키면 된다
전수인지 표본인지 모르겠으면KOSIS 표 위의 통계설명자료 → 조사 방법. "전국 모든 ~을 집계"면 전수, "~명을 뽑아 조사"면 표본
AI로 자료를 찾아도 되나검색어 고르기와 전문 자료 요약은 된다. 표·그래프·해석·결론은 직접 쓴다. 발표 뒤 질문에 답할 수 있어야 한다
친구와 같은 자료를 써도 되나된다. 주장·해석·결론은 각자 쓴다
외국 자료도 되나출처와 링크가 있으면 된다. 가능하면 국내 통계를 권한다

이 시간에 꼭 남겨야 할 세 문장

출발점주장은 통계로 정한다. 하고 싶은 주장이 있으면 받칠 통계를, 눈에 띈 통계가 있으면 거기서 할 주장을 생각해 온다. 책은 통계 활동에 조언을 얻는 참고다.
만들 것표 1(원자료 그대로, 출처·전수/표본) → 표 2(필요한 줄만 골라 다시) → 그래프(세로축 0, 제목·단위). 이 셋은 집에서 준비해 온다.
쓸 것칸마다 핵심만 4줄, 제목은 키워드. 해석은 숫자의 움직임, 결론은 통계를 근거로 한 내 의견. 발표에서 열 가지를 다 말한다.
