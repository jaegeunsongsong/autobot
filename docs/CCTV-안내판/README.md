# CCTV 안내판 (A4 세로, 210×297mm)

영유아 가족사진 스튜디오 '쁘띠레코드' 매장용 CCTV 안내판.

## 파일

| 파일 | 용도 |
| --- | --- |
| `cctv-안내판-A4.pdf` | 인쇄용 원본. A4 1쪽, 글꼴 임베드, 여백 0 |
| `cctv-안내판-미리보기.png` | 미리보기 이미지 (A4 비율, 2배 해상도) |
| `cctv-안내판-A4.html` | 디자인 원본. 글꼴이 base64로 내장되어 오프라인에서도 동일하게 보임. 브라우저 인쇄로도 PDF를 다시 만들 수 있음 |

## 디자인 규격

- 배경 크림 `#F5EFE6`, 제목·아이콘·본문 딥베리 `#6D2E46`, 가는 선·항목명·포인트 골드 `#B98A44`
- 글꼴: 제목 Jua, 본문 Gowun Dodum, 영문 Nunito (모두 Google Fonts, 오픈 라이선스)
- 제목 글자 크기 26mm, 본문 9.4mm, 항목명 6.2mm
- 테두리: 골드 2중 가는 선(0.5mm + 0.2mm), 모서리 둥글게
- 아이콘: 단순 선 그림 카메라 1개 (경고색·눈·해골 없음), 사람·아기 이미지 없음

## 인쇄 안내

- 용지 A4 세로, 배율 100% (맞춤 축소 금지), 여백 없음 또는 '실제 크기'로 인쇄
- 배경색이 인쇄되도록 '배경 그래픽 인쇄' 옵션 켜기
- 2m 거리에서 제목이 읽히도록 설계됨. 더 크게 필요하면 A3로 141% 확대 인쇄 가능
