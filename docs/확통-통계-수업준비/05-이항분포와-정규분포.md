## 1. 도입: 심플한 예시로 감 잡기

**칠판**: 동전 한 개를 100번 던질 때 앞면이 나온 횟수 X. 3차시 그대로 $X\sim B\left(100,\frac12\right)$.

- "앞면이 45번 이하일 확률은?" → $\sum_{x=0}^{45}{}_{100}C_x\left(\frac12\right)^{100}$. 항이 46개. 손으로는 불가능.
- 그런데 X의 확률분포를 **막대그래프**로 그리면(공학도구나 교과서 그림) 평균 50을 중심으로 한 종 모양이다. n이 클수록 더 매끈해진다.
- 그러면 **모양만 정규분포로 바꾸고 넓이로 구하자.** 평균과 분산은 이항분포 것을 그대로: $np=50$, $npq=25$ → $N(50,5^2)$.
- $P(X\le45)=P\left(Z\le\frac{45-50}{5}\right)=P(Z\le-1)=0.5-0.3413=0.1587$. 46개 항의 합이 표 한 번으로 끝났다.

**감각 한 줄**: "이항분포의 평균·분산은 그대로 쓰고, 모양만 정규분포로 바꾼다." (큰수의 법칙과 같은 방향: n이 크면 이항분포가 안정된 종 모양에 가까워진다.)

## 2. 개념 정리

- $X\sim B(n,p)$에서 n이 충분히 크면 $X$는 근사적으로 $N(np,\,npq)$를 따른다. ($q=1-p$)
- "충분히 크다"의 기준: $np\ge5,\ nq\ge5$. 교과서 문제는 모두 이 조건을 만족하도록 만들어져 있다.
- **4단계 절차**
  ① 상황 → $B(n,p)$ ② $np$, $npq$ 계산 → $N(np,\,npq)$, $\sigma=\sqrt{npq}$ ③ $Z=\dfrac{X-np}{\sqrt{npq}}$ ④ 표
- 역산형: $P(X\le k)=\alpha$가 주어지면 표에서 z를 찾아 $k=np+z\sqrt{npq}$.
- 비율로 주어진 조건은 **횟수로 바꾼다**: 1600대 중 47.5 % ↔ 760대.

### 자주 하는 실수

- 표준편차를 $npq$로 쓴다(제곱근을 안 씌움).
- B(n, p)를 세우지 않고 바로 "평균 몇, 표준편차 몇"을 추측한다 → 반드시 n, p를 적게 한다.

## 3. 예제 8 (기본 → 확장)

표준정규분포표 (예제 공통): P(0≤Z≤0.5)=0.1915, P(0≤Z≤1)=0.3413, P(0≤Z≤1.5)=0.4332, P(0≤Z≤2)=0.4772, P(0≤Z≤2.5)=0.4938, P(0≤Z≤3)=0.4987

### 예제 1 [기본] 도입 그대로

동전 한 개를 100번 던질 때 앞면이 나오는 횟수 X에 대하여 (1) X가 근사적으로 따르는 정규분포 (2) P(X≤45) (3) P(40≤X≤60)

**풀이** (1) $B(100,\frac12)$, $np=50$, $npq=25$ → $N(50,5^2)$ (2) $P(Z\le-1)=0.1587$ (3) $P(-2\le Z\le2)=0.9544$

**고쟁이** 578, 676

### 예제 2 [기본] 공식 적용

$X\sim B\left(48,\frac34\right)$일 때 P(33≤X≤42)

**풀이** $np=36$, $npq=48\times\frac34\times\frac14=9$ → $N(36,3^2)$.
$P\left(\frac{33-36}{3}\le Z\le\frac{42-36}{3}\right)=P(-1\le Z\le2)=0.3413+0.4772=0.8185$.

**고쟁이** 577

### 예제 3 [기본] 상황 번역

주사위 한 개를 180번 던질 때 2의 눈이 나오는 횟수가 35 이상일 확률은?

**풀이** ① $X\sim B\left(180,\frac16\right)$ ② $np=30$, $npq=180\times\frac16\times\frac56=25$ → $N(30,5^2)$ ③ $P(X\ge35)=P(Z\ge1)$ ④ $0.5-0.3413=0.1587$

**포인트** 578의 (1)(2)(3) 소문항이 바로 이 4단계다. 처음 몇 문제는 이 번호를 붙여 쓰게 한다.

**고쟁이** 578, 677, 678

### 예제 4 [기본→확장] 실생활

어느 약의 치유율이 60 %라 한다. 150명에게 투여했을 때 78명 이상이 치유될 확률은?

**풀이** $X\sim B(150,0.6)$, $np=90$, $npq=150\times0.6\times0.4=36$ → $N(90,6^2)$.
$P(X\ge78)=P\left(Z\ge\frac{78-90}{6}\right)=P(Z\ge-2)=0.5+0.4772=0.9772$.

**포인트** 경계가 평균 왼쪽이면 답이 0.5보다 커야 한다. 68-95-99.7 감각으로 검산(78은 m−2σ).

**고쟁이** 579, 680, 682

### 예제 5 [확장] 식에서 n, p 읽기 + 근사

$P(X=x)={}_{100}C_x\,p^x(1-p)^{100-x}\ (x=0,1,\cdots,100)$이고 E(X)=20일 때 P(24≤X≤30)

**풀이** n=100, $100p=20$ → $p=0.2$. $npq=100\times0.2\times0.8=16$ → $N(20,4^2)$.
$P(1\le Z\le2.5)=0.4938-0.3413=0.1525$.

**고쟁이** 580

### 예제 6 [확장] 역산: 경계값 k

동전 한 개를 400번 던질 때 앞면이 나오는 횟수 X에 대하여 P(X≤k)=0.9772를 만족시키는 k

**풀이** $B(400,\frac12)$ → $N(200,10^2)$. $P(X\le k)=0.9772=0.5+0.4772$ → $\frac{k-200}{10}=2$ → k=220.

**포인트** 4차시 예제 8(상위 k %)과 같은 역산. 678(P(X≤n)≤0.8413인 n의 최댓값)은 부등식 버전.

**고쟁이** 676, 678, 681

### 예제 7 [확장] 비율로 주어진 조건

어느 판매점에서 휴대폰이 팔릴 때 A사 제품일 확률은 50 %다. 한 달 동안 1600대를 판매했을 때 A사 제품의 비율이 47.5 % 이상 52.5 % 이하일 확률은?

**풀이** A사 제품 대수 $X\sim B(1600,\frac12)$, $np=800$, $npq=400$ → $N(800,20^2)$.
비율 → 대수: $1600\times0.475=760$, $1600\times0.525=840$.
$P(760\le X\le840)=P(-2\le Z\le2)=0.9544$.

**포인트** "비율 → 횟수"로 바꾸는 이 한 줄이 6차시 **표본비율**의 씨앗이다. 다음 시간에 $\hat p=\frac{X}{n}$으로 다시 만난다.

**고쟁이** 679, 683, 684

### 예제 8 [확장] 두 이항분포 비교

서로 다른 동전 2개를 동시에 100번 던질 때 한 개만 앞면이 나오는 횟수를 X, A·B 두 사람이 가위바위보를 162번 할 때 A가 이기는 횟수를 Y라 하자. P(X≤30)=P(Y≥k)를 만족시키는 k

**풀이** 한 개만 앞면일 확률 $\frac12$ → $X\sim B(100,\frac12)$ → $N(50,5^2)$. A가 이길 확률 $\frac13$ → $Y\sim B(162,\frac13)$, $np=54$, $npq=36$ → $N(54,6^2)$.
$P(X\le30)=P\left(Z\le\frac{30-50}{5}\right)=P(Z\le-4)$. $P(Y\ge k)=P\left(Z\ge\frac{k-54}{6}\right)$.
대칭이므로 $\frac{k-54}{6}=4$ → k=78.

**포인트** 표 값이 필요 없는 문제. "표준화한 경계가 같으면 확률이 같다"는 4차시 예제 7의 논리다.

**고쟁이** 675

## 4. 마무리: 01 확률분포 단원 흐름도 (5분)

- 확률변수 X가 **이산** → 표나 식으로 분포 → E(X), V(X), σ(X) → aX+b
- 이산 중에서도 "독립시행의 횟수"면 **이항분포 B(n, p)** → 평균 np, 분산 npq
- 확률변수 X가 **연속** → 확률은 넓이 → 종 모양이면 **정규분포 N(m, σ²)** → 표준화 Z → 표
- n이 크면 **B(n, p) ≈ N(np, npq)** 로 두 줄기가 만난다 (오늘)
