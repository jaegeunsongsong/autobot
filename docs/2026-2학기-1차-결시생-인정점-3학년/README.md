| 받은 파일 | 내용 |
| --- | --- |
| HWPX (4쪽) | 1쪽 학업성적관리규정 제20조 발췌, 2~4쪽 엑셀 화면 그림 3장 |
| XLSX (시트 3개) | `Sheet1` 산출 기초자료, `2학기 결시생 결시과목` 결시 목록, `Sheet3` 인정점 부여표 |

| PDF 2부 (131쪽, 참고) | 2026학년도 학업성적관리규정 전문(신·구 조문 대비표, 본문, 부록1~5) |

## 파일

| 파일 | 내용 |
| --- | --- |
| `검토-결과.md` | 검토 결과와 수정 문안 |
| `원문-규정발췌.md` | HWPX 1쪽 글 원문과 2~4쪽 그림 제목 |

학생 이름·점수가 든 엑셀 원자료와 그림은 개인정보라 이 폴더에 넣지 않았다.
검토 결과에서는 학생을 반과 시트 행 번호로만 가리킨다.

## 검토 방법

```bash
pip install python-hwpx pillow lxml openpyxl
python3 tools/hwpx_extract.py <파일.hwpx> --out out/ --md --txt --tables --images
```

- HWPX는 `tools/hwpx_extract.py`로 글·표·그림을 뽑았다.
- XLSX는 openpyxl로 수식과 계산값을 모두 읽고, 숨긴 행·열과 인쇄 영역까지 확인했다.
- 인정점 15건은 규정 ③의 공식과 `Sheet1` B3의 반올림 절차대로 다시 계산해 대조했다.
- 결시 과목과 기준 과목이 실제 1차 시험(10/2~10/8)에 있었는지는 같은 레포의
  `docs/2026-2학기-1차-정기시험/원문-3학년.md` 시간표로 대조했다.
