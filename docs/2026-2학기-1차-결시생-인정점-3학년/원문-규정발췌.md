# 규정 발췌 원문 (HWPX 1쪽)

HWPX 1쪽에 실린 글만 옮겼다. 2~4쪽은 엑셀 화면을 찍은 그림 3장이라 글자가 없다. 그림에는 학생 이름과 점수가 있어 이 폴더에 넣지 않았다.

```
[관련 근거: 2026학년도 학업성적관리규정 제20조(인정점 부여)]

제20조(인정점 부여)
 ② 정기시험 인정점을 부여하는 기준 점수는 해당 학기 내 정기시험 성적을 기준으로 산출함을 원칙으로 하되,
    해당 학기 정기시험 성적이 없는 경우에는 아래의 ‘해당 학기에 기준 점수(정기시험)가 없는 경우의
    인정점 부여 방법’에 따라 인정점을 부여한다.

   < 해당 학기에 기준 점수(정기시험)가 없는 경우의 인정점 부여 방법 >
   1. 해당 학생의 해당 학기 동일 교과(군)의 정기시험 점수
   2. 해당 학생의, 해당 학기의 전 과목* 정기시험 평균 점수를 이용
      *전 과목: 해당 학생이 해당 학기에 응시한 정기시험 과목 전체(결시 과목 제외) 평균점수
   3. 해당 학생의 이전 학기* 동일 교과(군)의 정기시험 점수
      *이전 학기: 원칙적으로 직전 학기 동일 교과(군)의 정기시험 점수를 우선적으로 활용하되,
       직전 학기 동일 교과(군)의 점수가 없는 경우 그 이전 학기 등으로 차례대로 거슬러 올라갈 수 있음

 ③ 평가별 난이도 차이에 따른 유불리를 최소화하기 위하여 인정점 부여 시 다음 공식을 이용하여 점수를 산출한다.

    결시 과목의 점수(인정점) = 기준정기시험 해당학생 과목점수 × 결시정기시험 과목평균
                              ─────────────────────────────────────────────── × 인정점 비율
                                          기준정기시험 과목평균

    예) 응시한 1차 정기시험 과목점수: 해당 학생 과목점수(65점), 해당 과목 평균(50점)
        결시한 2차 정기시험 과목점수: 해당 과목 평균(75점)

    질병 결시한 2차 정기시험 점수 = (65×75/50) × 0.8 = 78

 ⑤ 100% 인정점으로 부여하는 경우
   10. 상급학교 진학 시험, -----------의 경우 해당 일에 한하여 학업성적관리위원회의 심의를 통하여
       학교장이 인정하는 결시

 ⑥ 80% 인정점으로 부여하는 경우
   1. 질병으로 인한 결시
    가. 결시한 날부터 5일 이내에 의사의 진단서 또는 의견서(병명, 진료기간 등이 기록된 의사 소견서,
        진료 확인서 등의 증빙서류)를 첨부한 결석계를 제출하여 학교장의 승인을 받은 경우
```

## 2~4쪽 그림의 제목

| 쪽 | 그림 제목 | 엑셀의 어느 시트인가 |
| --- | --- | --- |
| 2 | 2026학년도 2학기 정기시험 결시 과목 및 결시 사유 | `2학기 결시생 결시과목` 시트 (3학년 7명, 결시 과목 37개) |
| 3 | 2026학년도 2학기 결시생 인정점 부여(수동 입력) | `Sheet3` 아래쪽 표 (반올림값 수동 입력, 15건) |
| 4 | 2026학년도 2학기 결시생 인정점 산출 기초 자료(3학년) | `Sheet1` (P·Q열 숨김 상태) |
