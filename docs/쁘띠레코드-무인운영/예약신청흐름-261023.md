# 쁘띠레코드 예약 신청 흐름 (261023 · 대표 원문)

PDF `쁘띠레코드_예약신청흐름_261023.pdf`의 원문이다. 그림은 `예약신청흐름-261023.html`(폰트 CSS만 끼우면 다시 뽑을 수 있음).

```
[손님] 인스타·카톡·당근·블로그 → 네이버 예약 링크
   │      (전화 손님만 ▶ [대표]가 네이버에 직접 등록)
   ▼
[손님] 상품 선택
   │   베이직 13만 (4명·2시간, 30분 단위로 최대 4시간 · 30분 25,000)
   │   패밀리 27만 (8명·4시간, 최대 8시간 · 30분 25,000)
   │   추가 인원 베이직 15,000 / 패밀리 12,000 (최대 15명)
   ▼
[손님] 날짜·시작 시간 선택 → 추가 질문
   │   ① 방문 총인원 (필수)
   │   ② 기념일 종류 (필수: 백일·돌·생일·칠순·환갑·가족사진·기타)
   │   ③ 아기 이름 (선택)
   ▼
[손님] [신청] — 결제 없음
   │
   ├──▶ [자동] 네이버 "신청 접수" 알림 → 손님
   │        내용: 입금액(이용료+보증금 5만) · KB 계좌 · 3시간 기한
   │              (22시 이후 신청 → 다음 날 10시) · 입금자명 = 예약자명
   │              · 다른 이름이면 채널로 알려 달라
   │        🟡 문구 넣기 안 되면 ▶ ⓪ 예약 접수 알림톡으로 대신
   │
   └──▶ [자동] 스마트플레이스 "새 예약 신청" 푸시 → 대표
            ▼
        [대표] 겹치는 예약 있나?
            ├─ 있음 ▶ 네이버 [거절] ── 끝
            └─ 없음
                ▼
        [대표] 시트에 3칸 입력: 이름 · 전화 · 받을 금액 (상태 = 신청)
                │   (이때 손님에게 나가는 알림톡 없음)
                ▼
        [자동] 시트가 입력 시각 기록 → 3시간 타이머 🟡(스크립트 추가)
```
