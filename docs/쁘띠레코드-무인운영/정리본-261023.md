## 3. 알림톡

| 템플릿 | 언제 | 보내는 방법 |
|---|---|---|
| ① 확정·비번 | 시트 상태 '입금확인' 뒤 10분 안 | 시트 자동 |
| ② 퇴실 안내 | 예약 종료 시각(연장 무관) | 시트 자동 |
| ③ 일회용 비번 | 당일 미입금 · 비번 오류 · 재입장 | 솔라피 콘솔 수동 |
| ⑤ 점검 결과 | 차감 있는 팀, 반환 전 | 솔라피 콘솔 수동 |
| ⓪ 예약 접수 | 네이버 신청 알림에 계좌를 못 넣을 때만 🟡 | 조건부 |
| 출입 안내 | 원격 비번이 안 될 때만, 전날 21시 🟡 | 조건부 |

오픈 조건 = ①②③⑤ 승인(②가 끝내 반려되면 ①③⑤). 템플릿 = 카카오가 승인한 정해진 문안, 변수 `#{고객명}` 등은 보낼 때 채움.

## 4. 시트 (자동 발송 + 이체·페이백 기록)

| 열 | 내용 | 누가 |
|---|---|---|
| A~F | 예약자명 · 전화 · 이용일 · 시작 · 종료 · 상품 | 대표(신청 때) |
| G·H | 비밀번호 · 상태(신청 → 입금확인 → 확정 → 이용완료 / 취소) | 대표는 '입금확인'까지, 뒤는 스크립트 |
| I~K | ①발송 · ②발송 · 비고(오류) | 스크립트 |
| L~S | 반환 계좌 · 보증금 반환일 · 차감액·사유 · 리뷰 1만 지급일 · 블로그 2만 지급일 · 취소 환불액·일 · 현금영수증(발급/취소) · 메모 | 대표(21시 루틴) |

스크립트 `알림톡-자동발송.gs`: 10분마다 실행, testMode로 먼저 시험, API 키가 들어 있으니 시트는 대표·남편만 공유.
