# 네이버 예약(스마트플레이스) '부분취소' 업종별 적용 여부 조사 보고서

## 요약

- 대행사 답변("부분취소는 뷰티 업종만")은 **지지하는 공식 근거도, 반박하는 공식 근거도 하나도 확인되지 않았다.** 이번 조사 환경에서 네이버 공식 도움말(help.naver.com)·스마트플레이스 공지는 접근 자체가 실패했고, 도메인 제한 검색은 모두 0건이었다. 따라서 "맞다/틀리다"를 단정할 수 없다.
- 비공식 자료(블로그 2건, 2026-10)는 부분취소를 "업체가 해당 기능을 제공(설정)하는 경우에만 가능"으로 설명하고, 최신 뉴스(2026-09-14)는 스마트플레이스 기능이 '업종' 자체보다 **'예약 유형'(일반형·식당형·뷰티형)** 단위로 갈리는 구조임을 보여 준다. 두 자료는 대행사 주장과 논리적으로 양립 가능하다(뷰티형 유형에서만 설정이 열려 있다면 결과적으로 업종 제한처럼 보일 수 있음).
- 질문자가 원하는 구조(이용료 + 보증금 옵션 50,000원 네이버페이 결제 → 이용 후 옵션만 부분취소)가 '아기사진전문' 업종 + '시간 선택형' 상품에서 가능한지는 **현재 확인 불가**다. 사진관·스튜디오·공간 업종에서 옵션 부분취소를 실제로 쓴 공개 사례도 발견되지 않았다.
- 가장 현실적인 길은 두 갈래다. (1) 스마트플레이스 고객센터 1:1 문의 또는 최소 금액 테스트 예약 1건으로 부분취소 버튼 노출 여부를 직접 확인하기, (2) 그때까지는 **보증금을 네이버페이 선결제에서 분리**해 이용료만 네이버페이로 받고 보증금은 계좌로 받아 이용 후 반환하는 방식(질문자 측 기존 운영안과 동일, 공간 업체 '쏘플' 사례와도 같은 구조)을 유지하기.
- 조사 한계: 1차 조사 이후 검증 단계에서는 검색 예산 소진으로 추가 검색이 전혀 수행되지 않아, 모든 핵심 주장의 확실도는 '추정' 이하다. 아래 "네이버에 직접 물어볼 질문 목록"을 그대로 보내 확정하는 것을 권한다.

**대안 C — 전체취소 후 이용료만 재결제**
- 공식(다른 상품 유형): 네이버페이센터 '주문형' 가이드 — "일부 상품만 취소할 때 최초 결제한 내역을 모두 취소하고 남을 상품 대금만 다시 결제하는 방식" / "재결제가 끝나면 최초 결제는 자동 취소" / "부분취소가 불가능한 결제수단은 재결제가 필요할 수 있습니다". https://campaign-cdn.pstatic.net/filemanager/static/naverpay_guide/pdf/10_주문형_취소반품교환관리_713.pdf (날짜 미상)

## 반박 여부 표시

검증 단계(렌즈: check)에서 **"반박됨"으로 판정된 주장은 없다.** 단, 이는 반박 근거를 찾은 것이 아니라 검색 예산 소진으로 추가 검증을 수행하지 못한 결과이며, 모든 주장의 확실도가 '추정' 또는 '모름'으로 하향되었다. 조정 내용:

## 네이버에 직접 물어볼 질문 목록 (스마트플레이스 고객센터 1:1 문의용, 복사해 붙이기)

> 광주 소재 영유아 사진 스튜디오입니다. 네이버 플레이스 업종은 '아기사진전문'이고, 예약 상품은 베이직(2시간 130,000원)·패밀리(4시간 270,000원) 2개를 '시간 선택형'(시작~종료 시간 선택)으로 운영합니다. 손님이 네이버페이로 [이용료 + 보증금 옵션 50,000원]을 함께 결제한 뒤, 이용 후 사업자가 보증금 옵션만 부분취소해 돌려주는 운영을 검토 중입니다. 아래를 확인해 주세요.

1. "업종 '아기사진전문'(사진·스튜디오 계열) 사업장에서 네이버페이 결제 예약의 '부분취소'(옵션만 취소) 기능을 사업자가 설정·사용할 수 있나요? 부분취소가 가능한 업종 또는 예약 유형 목록이 있다면 알려 주세요."
2. "부분취소 기능이 특정 예약 유형(예: 뷰티형)에서만 제공되는 것이라면, 일반형·시간 선택형 상품에서는 제공되지 않는 것인지 확인해 주세요."
3. "사진 스튜디오 업종에서 네이버페이 결제 예약의 옵션 항목만 부분취소한 운영 사례나 적용 가능 여부를 안내해 주실 수 있나요?"
4. "'시간 선택형' 예약 상품에서 네이버페이로 [이용료 + 옵션(보증금 50,000원)]을 함께 결제한 경우, 사업자가 옵션 항목만 부분취소할 수 있나요? 메인 이용료는 부분취소 대상이 아니고 옵션만 가능하다는 규칙이 있나요?"
5. "쿠폰(또는 포인트)을 사용해 네이버페이로 결제한 예약은 사업자가 옵션 부분취소를 할 수 없는 것이 맞나요? 맞다면 쿠폰 사용 예약의 보증금 옵션 환불은 어떻게 처리해야 하나요?"
6. "예약 상태가 '이용완료'(방문 후)로 바뀐 뒤에도 사업자가 해당 예약의 옵션 항목(보증금 50,000원)만 부분취소·환불할 수 있나요? 가능하다면 이용완료 후 며칠(또는 몇 개월) 이내까지 가능한가요?"
7. "부분취소로 환불된 금액은 손님에게 결제수단별로 며칠 안에 돌아가며, 사업자 정산에는 어떻게 반영되나요?"
8. "스마트플레이스센터에서 네이버페이 결제 예약의 '부분취소'를 허용하는 설정은 어느 메뉴에 있나요? (예약 상품 설정, 네이버페이 설정, 예약 상세 화면 중) 단계별 경로를 안내해 주세요."

10. "일반형·시간 선택형 상품에서 '보증금(이용 후 전액 반환)'을 네이버페이 결제에 포함해 받고 이용 후 사업자가 환불하는 공식 방법이 있나요? 없다면 네이버가 권장하는 보증금 운영 방식은 무엇인가요?"
11. "예약 상품 등록 시 '예약금 받기' 확정 방식과 환불기준(취소 수수료) 설정은 '아기사진전문' 업종의 시간 선택형 상품에서도 사용할 수 있나요?"
