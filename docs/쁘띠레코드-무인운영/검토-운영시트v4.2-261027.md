검증 방법: v4.2 전체를 자바스크립트 파서로 검사 → **통과**. 2차 수정 1~5의 문자열·조건문을 스크립트로 대조 → **5개 모두 반영됨**(수정 1 `\n` 문자열, 수정 2 '대기:' 기록 ①·⑤, 수정 3 `endAt <= startAt` + 시간(h)≤0 빨강, 수정 4 TEST_PHONE 검사, 수정 5 메일에 시트 링크). 문자열 안 실제 줄바꿈 없음.

## 고칠 코드 (설치 전 권장: A · 설치 후 여유 있을 때: B·C·D)

### 수정 A — 지난 날짜에 ① 보내지 않기 (168~169줄 사이)
```js
    if (status === '확정' && (!v('① 결과') || pending(v('① 결과')))) {
      if (!v('비밀번호')) { sh.getRange(rowNo, C['① 결과']).setValue('대기: 비밀번호 입력 필요'); continue; }
      if (endAt < now) { sh.getRange(rowNo, C['① 결과']).setValue('대기: 이용 시간이 이미 지남 (이용일·종료 확인)'); continue; }
```
(정말 지난 예약에 보내야 하면 결과 칸에 아무 글자나 적고 지우는 대신, 이용일을 맞게 고치면 됨. 시험 3단계 "종료 시각 지난 뒤 실행"은 ①이 이미 '성공'이라 영향 없음. 단, 시험 1단계에서 종료를 "지금+5분"으로 적고 5분 안에 ①까지 끝내야 함 → 가이드에 "종료는 지금+15분"으로 늘릴 것.)

### 수정 C — 응답 해석 실패는 '실패:'가 아니라 '확인필요'로 (243~248줄)
```js
  const code = res.getResponseCode();
  if (code >= 300) throw new Error('솔라피 ' + code + ' ' + res.getContentText().slice(0, 150));
  let json;
  try { json = JSON.parse(res.getContentText()); }
  catch (e) { return (test ? '성공(테스트)' : '성공') + ' 응답해석실패-솔라피내역확인'; }   // 접수는 됐을 수 있으니 재발송 금지
  const failed = json.failedMessageList || [];
  if (failed.length) throw new Error(failed[0].statusMessage || failed[0].statusCode || '발송 실패');
  return test ? '성공(테스트)' : '성공';
```

## 결론

**설치 진행 가능.** 구문 통과, 2차 수정 5개 모두 반영, 차단급 문제 없음. 설치 전에 수정 A(지난 날짜 방지) 한 줄만 넣기를 권하고, 가이드는 5·6번 문구와 시험 1단계 "종료 = 지금+15분"만 고치면 코드와 맞는다. B·C·D는 시험이 끝난 뒤 여유 있을 때.
