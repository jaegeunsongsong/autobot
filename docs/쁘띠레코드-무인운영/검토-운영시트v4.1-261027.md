## 고칠 코드

### 수정 1 — checkConfig 전체 교체 (구문 오류)
```js
function checkConfig() {
  const keys = ['SOLAPI_KEY', 'SOLAPI_SECRET', 'PF_ID', 'TPL_CONFIRM', 'TPL_THANKS', 'TPL_CHECK', 'SENDER', 'TEST_PHONE', 'TEST_MODE'];
  const msg = keys.map(k => k + ': ' + (cfg(k) ? (k.indexOf('SOLAPI') === 0 ? '입력됨' : cfg(k)) : '❌ 비어 있음')).join('\n');
  const tz1 = Session.getScriptTimeZone(), tz2 = SpreadsheetApp.getActive().getSpreadsheetTimeZone();
  const warn = (tz1 !== 'Asia/Seoul' || tz2 !== 'Asia/Seoul')
    ? '\n\n❌ 시간대: 스크립트=' + tz1 + ' / 시트=' + tz2 + ' → 둘 다 Asia/Seoul로 (프로젝트 설정 · 파일 > 설정)'
    : '\n\n시간대 OK';
  SpreadsheetApp.getUi().alert(msg + '\nALERT_EMAIL: ' + (cfg('ALERT_EMAIL') || '(없음)') + warn);
}
```
붙여 넣은 뒤 저장 버튼 옆에 빨간 오류 표시가 없는지, 메뉴 [쁘띠레코드]가 뜨는지로 확인.

### 수정 2 — 시간 누락·오류는 '대기:'로 적고 ⑤에도 남김 (157~164줄 교체)
```js
    let startAt, endAt;
    try {
      if (!v('시작') || !v('종료')) throw new Error('시작·종료 시간 입력 필요');
      startAt = toDate(v('이용일'), v('시작')); endAt = toDate(v('이용일'), v('종료'));
      if (endAt <= startAt) throw new Error('종료가 시작보다 빠름');
    } catch (e) {
      const note = '대기: ' + e.message;
      if (status === '확정' && (!v('① 결과') || pending(v('① 결과')))) sh.getRange(rowNo, C['① 결과']).setValue(note);
      if (String(v('보증금')) === '차감(⑤발송)' && (!v('⑤ 결과') || pending(v('⑤ 결과')))) sh.getRange(rowNo, C['⑤ 결과']).setValue(note);
      continue;
    }
```
('대기:'는 이미 노랑 규칙·재시도 규칙에 걸리므로 시간을 고치면 다음 실행에 저절로 나감.)

### 수정 3 — 종료 ≤ 시작 검사
수정 2의 `if (endAt <= startAt) throw …` 한 줄이 그것. 시트 쪽에도 경고 색 한 줄:
```js
    rule(`=AND(ISNUMBER($${h}${r}),$${h}${r}<=0)`, '#f4c7c3'),   // 시간(h)이 0 이하
```

## TEST_MODE=Y 시험에서 놓치기 쉬운 것

1. **첫 실행은 권한 창**: '지금 한 번 실행'을 처음 누르면 외부 연결(UrlFetch)·메일 권한을 묻는다. 허용하지 않으면 트리거도 조용히 실패한다. 실행 기록(Apps Script 좌측 '실행')에서 오류 여부 확인.
2. **설정 확인 → "시간대 OK"** 를 먼저 본다. 시트 시간대가 다르면 ②가 몇 시간 어긋난다.
3. **템플릿 변수명 불일치**는 솔라피가 `failedMessageList`로 돌려주므로 ① 결과에 "실패: …" 로 뜬다. 이때 변수명(`#{시작}` 등)이 승인 템플릿과 글자까지 같은지 본다.
4. **대체 문자(LMS)는 시험으로 강제할 수 없다**(카톡 실패 때만 나감). 솔라피 콘솔 발송 내역에서 "대체발송 설정됨"이 보이는지로 대신 확인. TEST_PHONE에 카톡이 있으면 알림톡만 온다.
5. **시험 줄 정리 순서**: 시험 줄을 지우거나 상태 '취소'로 바꾼 **다음** TEST_MODE=N. 반대로 하면 10분 안에 시험 줄의 ②가 실제 번호로 나갈 수 있다.
6. **② 시험**은 종료 시각을 지금보다 5분 뒤로 적고 10분 기다리거나 '지금 한 번 실행'. ① 결과가 '성공(테스트)'로 시작해야 ②가 나간다.
7. **⑤ 시험**: 보증금 '차감(⑤발송)'만 고르고 점검내용·차감금액을 비워 두면 ⑤ 결과가 '대기:'(노랑)가 되는지, 채우면 다음 실행에 나가는지까지 본다.
8. **제목 행이 주황**이면 테스트 모드. N으로 바꾼 뒤 다음 실행에서 보라색으로 돌아오는지 확인.
9. '발송중'이 남은 행이 생기면(빨강) 솔라피 발송 내역에서 그 시각에 나갔는지 보고, 나갔으면 결과 칸에 "성공 수동확인", 안 나갔으면 칸을 비워 재발송.
