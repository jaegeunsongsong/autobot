# 강대모의고사K 31회 · 60분 편집본

원본: 2026학년도 대학수학능력시험 강대모의고사K 31회 수학 영역(스캔 PDF).
원본에서 4점 문항만 발췌해 60분용 모의고사로 다시 조판한 것이다.

## 편집 조건

- 공통 8~14번·18~21번, 선택 26~29번 수록 (1~7, 15~17, 22~25, 30번 제외)
- 문항 번호는 원본 번호 그대로 유지
- 표지 없음, 수능 문제지 2단 양식(머리글·단 구분선·쪽 번호·확인 사항 상자) 유지
- 선택과목별 3개 버전(확률과 통계 / 미적분 / 기하), 각 버전에 정답표 + 원본 해설 발췌본 별도 제작

## 구성 (15문항 · 55점 · 60분)

|---|---|---|
| 공통 5지선다형 | 8(3점), 9, 10, 11, 12, 13, 14 | 27점 |
| 공통 단답형 | 18(3점), 19(3점), 20, 21 | 14점 |

문제지는 4쪽(공통 3쪽 + 선택 1쪽), 정답 및 해설은 8쪽이다.

## 인쇄

페이지 크기는 원본 스캔과 같은 216 × 321 mm이다. A4나 B4로 인쇄할 때는 프린터 설정에서 "용지에 맞춤(페이지 크기에 맞게 축소/확대)"을 선택한다.

## 제작 방법

`tools/강대K31회-60분편집/`의 스크립트로 만들었다.

1. `pdftoppm -r 300`으로 원본 PDF 전 쪽을 PNG로 렌더
2. `detect.py` — 문제 쪽의 머리글 괘선·단 구분선·문항 블록 좌표 검출
3. `detect_sol.py` — 해설 쪽의 문항별 해설 머리(`N. ___ 정답`) 위치 검출
4. `build.py` — 문항·머리글 요소를 잘라 2단 양식으로 재조판하고, 해설 조각을 단 흐름에 맞춰 이어 붙여 PDF 생성

스크립트의 작업 경로(`SP`)는 작성 당시의 임시 디렉터리를 가리키므로, 다시 실행하려면 렌더 PNG 위치에 맞게 수정해야 한다. 한글 글꼴은 PyPI `koreanize-matplotlib` 패키지에 포함된 나눔고딕을 사용했다.
