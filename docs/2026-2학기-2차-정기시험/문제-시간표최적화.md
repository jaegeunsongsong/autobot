# 고등학교 정기시험 시간표 최적화 문제

당신은 조합 최적화 문제를 푸는 역할입니다. 아래 데이터와 제약을 모두 만족하면서 평가 지표를 개선하는 **2학년 시험 시간표**를 찾아 주세요. 현재 최선안(baseline)을 함께 드립니다. **그보다 나은 안이 있는지** 찾고, 없다면 왜 없는지 설명해 주세요.

추측하지 마세요. 아래 데이터에 없는 사실을 가정하면 안 됩니다.

## 1. 상황

- 2026학년도 2학기 2차 정기시험. 4일간: **12/10(목) / 12/11(금) / 12/14(월) / 12/15(화)**
- **1학년** 156명: 6과목, 전원 공통. 금·월·화 3일 응시. **목요일은 정상 수업.**
- **2학년** 176명: 16과목, 선택형. 목·금·월·화 4일 응시. **전원 예외 없이 1인당 정확히 8과목.**
- **3학년**: 2차 지필평가 **없음**. (등교하며 3학년 교실은 다른 학년이 쓰지 않음)

### 사용 가능한 교시 (중요)
- **2학년**: 목·금·월은 **2, 4, 5, 7교시**. 화요일은 **2, 4교시만** (4교시 후 중식 뒤 귀가).
- **1학년**: 금·월은 **2, 7교시**. 화요일은 **2, 4교시**. (목요일은 1~7교시 정상 수업)
- 학년 간 교시를 맞추는 이유는 한 학년이 시험 볼 때 다른 학년이 돌아다녀 소란해지는 것을 막기 위함입니다. 3·6교시를 새로 여는 안은 원칙적으로 피하되, 지표가 크게 개선되면 제안해도 됩니다(단점 명시 필수).

### 교시 슬롯 수 (핵심 제약)
2학년 가용 교시는 **목4 + 금4 + 월4 + 화2 = 14개**인데 과목은 **16개**입니다.
따라서 **정확히 2개 교시에서 두 과목을 동시 시행**해야 합니다(같은 시각, 다른 시험실).
동시 시행하려면 **두 과목을 모두 듣는 학생이 0명**이어야 합니다.

전수 조사 결과 **겹침 0인 쌍은 정확히 2개뿐**입니다.

- `동아시아역사기행 + 세포와물질대사` (겹침 0명)
- `프로그래밍 + 심화중국어` (겹침 0명)

따라서 **이 두 쌍은 반드시 각각 같은 교시에 묶여야 합니다.** 다른 조합으로는 해가 존재하지 않습니다.
(그 다음으로 적은 겹침은 심화일본어+심화중국어 1명, 화학반응의세계+동아시아역사기행 1명 등으로 모두 0이 아님)

## 4. 제약 조건

### (가) 절대 제약 — 위반 불가

1. **학생 동시 응시 불가**: 같은 교시의 두 과목을 모두 듣는 학생이 **0명**이어야 함.
2. **담당교사 동시 배치 불가**: 같은 날 같은 교시에 한 교사가 두 과목(1학년 과목 포함)을 담당할 수 없음. 공동 담당자는 **전원이 자기 과목 시험 시간에 대기**해야 함.
3. **전이슬 출장**: 전이슬(심화중국어 P 담당)은 **화요일·목요일 1~4교시** 외부 학교 출장. 그 시간대 배치 불가.
   - 화요일은 2·4교시뿐이므로 **P는 화요일 배치 불가**.
   - 목요일이면 **5교시 또는 7교시만** 가능.
4. **목요일 1학년 수업 충돌**: 목요일은 1학년 정상 수업. 그 교시에 1학년 수업이 있는 교사는 2학년 시험 담당 불가.

   목요일 1학년 수업 담당표 (교시별, 1~8반 순):

   | 교시 | 담당 교사 |
   |---|---|
   | 1 | 윤정희 손경준 곽준철 박경애 이바다 김미애 김태현 최지혜 |
   | 2 | 이바다 김태현 강승희 강진원 손경준 조세라 유경희 최가연 |
   | 3 | 유경희 문준성 박경애 곽준철 최지혜 강승희 김순선 최진호 |
   | 4 | 최지혜 최진호 김미애 노석환 최가연 이바다 박경애 손경준 |
   | 5 | 김태현 강승희 김순선 이바다 박현수 곽준철 정인광 유경희 |
   | 6 | 조세라 최지혜 문준성 유경희 곽준철 박경애 강승희 김태현 |
   | 7 | 이호성 윤정희 석경훈 김순선 정인광 최지혜 최가연 박경애 |

   2학년 과목 담당자만 추리면 (2학년 가용 교시 2·4·5·7 기준):
   - **김미애** (E): 목 1·4교시 수업 → E는 목요일이면 2·5·7교시만
   - **조세라** (M): 목 2·6교시 → M은 목요일이면 4·5·7교시만
   - **최진호** (H): 목 3·4교시 → H는 목요일이면 2·5·7교시만
   - **노석환** (I): 목 4교시 → I는 목요일이면 2·5·7교시만
   - **정인광** (O): 목 5·7교시 → O는 목요일이면 2·4교시만
   - **손경준** (O): 목 1·2·4교시 → O는 목요일이면 5·7교시만
   - 정인광과 손경준이 O를 **공동** 담당하므로 **O(=O+J 쌍)는 목요일 배치 불가**(2·4·5·7이 전부 막힘).

5. **3학년 담임 및 정재훈은 월·화요일 불가**(원칙).
   3학년 담임: 최광진, 배태안, 박현수, 김영주, 변영민, 남재현, 손경준, 김수현 (+정재훈)
   이 중 1·2학년 2차 지필 과목 보유자는 **3명뿐**:
   - **배태안** — J 세포와물질대사 (단독 담당)
   - **손경준** — O 동아시아역사기행 (정인광과 공동) + 1학년 한국사2 (정인광과 공동)
   - **박현수** — 1학년 통합사회2 (4인 공동, 대기만 하면 됨)

   **예외 운용**: 예외를 허용하되 반드시 **월·화요일 2교시(09:45~10:35)** 에 배치해 오전에 끝낼 것. 그 외 교시의 월·화 배치는 불가.
   - 박현수는 1학년 통합사회2가 월요일이므로 **월 2교시 배치가 사실상 확정**.
   - 배태안·손경준의 예외 사용 여부는 **선택지**입니다. 예외를 쓰지 않으면 O+J 쌍은 **금요일**에만 갈 수 있습니다(4번에 의해 목 불가, 5번에 의해 월·화 불가).

6. **하루 0과목 금지**: 2학년 176명 전원이 **4일 모두 최소 1과목 이상** 응시해야 함.

### (나) 강한 선호 — 어기면 명시하고 근거를 댈 것

7. **4회 응시 0명** (하루 4과목 보는 학생 없음).
8. **마지막 날(화) 3회 응시 0명**.
9. **교사 하루 2과목 0건** (1학년 과목 포함). 주의 대상:
   - 김미애: E + 통합사회2(월) → **E는 월요일 불가**
   - 노석환: I + 통합사회2(월) → **I는 월요일 불가**
   - 최진호: H + 통합과학2(화) → **H는 화요일 불가**
   - 조세라: M + 통합과학2(화) → **M은 화요일 불가**
   - 구성희: B + D → **B와 D는 서로 다른 날**
   - 정인광·손경준: O + 한국사2(금) → **O가 금요일이면 같은 날 2과목**이 됨
10. **A·B·C는 서로 다른 날**. 셋 다 전원 과목이라 같은 날이면 부담 과도.
11. **같은 날 같은 교과(계열) 2과목 최소화**. 계열은 2절 표의 "교과(계열)" 열 기준.
    - 수학(B·D)은 **같은 날만 아니면 되고, 연속된 날이어도 무방**합니다.
12. **3회 응시 인원이 많은 날은 가능한 한 앞 일차(목요일)로**. 시험 전 준비 기간이 길기 때문. 2일차에 몰리면 1일차 밤 하룻밤만 주어짐.

### (다) 참고

- 시험실: 2학년 2-1 ~ 2-9 **9실**, 1실 약 20명. 어느 교시든 9실 이하. (전원 과목 176명 = 9실)
- 시험 없는 학생은 자기 교실 자습.
