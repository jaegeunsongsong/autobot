# 2026학년도 2학기 2차 정기시험 시간표 최적화 (조대부고)

12/10(목)~12/15(화) 나흘간 2학년 16과목(선택형, 1인 8과목)과 1학년 6과목을 배치하는 조합 최적화 결과다.
의뢰서의 학생 데이터(84개 수강 조합·176명)와 제약을 그대로 코드로 옮겨 전수 탐색했다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `최적화-결과.md` | 데이터 검산, 탐색 방법과 공간 크기, 기존 사실 재검증, 핵심 결론과 증명, 다섯 안(배치표·분포표·제약 점검표·기회비용), 비교표와 추천, 남은 질문 |

## 탐색 코드

`tools/exam2026_2_2/` 에 있다. 요일 배정은 OR-Tools CP-SAT 로 전수 열거하고, 교시 배정은 요일별 순열을 전수 검사한다.
재현 방법은 `최적화-결과.md` 8절에 있다.
