## 결과 요약

21문항의 정답은 모두 맞다. 부록의 배점·정답 분포·커버리지 수치와 채점기준표의
단계 배점에도 산술 오류가 없다. 고칠 곳은 성취기준 코드와 채점기준표에 몰려 있다.

| 구분 | 건수 |
| --- | --- |
| 계산·대조로 확정된 곳 | 15 |
| 확인이 필요한 곳 | 8 |
| 제 의견 | 15 |

특히 급한 것은 다음 다섯이다.

1. 19번 성취기준 `[12수학Ⅰ03-08]`은 존재하지 않는 코드다 (→ `03-07`)
2. 9번 `[12수학Ⅰ03-07]`은 수학적 귀납법 코드다 (→ `03-06` 귀납적 정의)
3. 3번 `[12수학Ⅱ03-02]`는 부정적분 코드인데 정적분 문항이다 (→ `03-04`)
4. 16번 채점기준 [후한 적용] 두 항이 같은 답안에 4점과 5점을 지시한다
5. 15·17번 채점기준이 공통 원칙과 충돌해 답이 틀린 답안에 만점이 가능하다

## 검토 방법

문항 21개를 각각 독립 검토자에게 맡겨, 시험지의 풀이를 보지 않고 문제만으로 먼저 풀게
한 뒤 대조했다. 모든 계산은 sympy로 검산했다. 서술형 채점기준 8개는 전형적인 답안을
만들어 기준표대로 채점해 보고 점수가 갈리는 지점을 찾았다. 공통 채점 원칙, 부록 수치,
성취기준 코드, 문서 체재, 출제 설계, 표기를 각각 따로 훑었다.

시험명·과목명·출제범위·시험 시간은 `docs/2026-2학기-1차-정기시험/원문-3학년.md`의
가정통신문과 대조했다.

EBS 수능완성 원본(`26054-XXXX`)은 이 환경에 없어 출처 대조는 하지 못했다.
