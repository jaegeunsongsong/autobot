# 고3 「수학적 사고와 적분」 정기시험 출제 검토

조선대학교부속고등학교 2026학년도 2학기 1차 정기시험(시행 2026. 10. 8. 목 1교시) 3학년 「수학적 사고와 적분」 시험지와 서술형 채점기준표를 검토한 결과다.

**21문항의 정답은 모두 맞다.** sympy로 독립 재계산했고, 조건에서 함수를 역결정하는 11·13번은 해의 유일성까지 확인했다. 부록의 배점·정답 분포·커버리지 수치와 채점기준표의 단계 배점도 셀 단위로 대조해 산술 오류는 한 건도 없었다.

고칠 곳은 문항이 아니라 **성취기준 코드와 채점기준표**에 몰려 있다.

확인한 것과 의견을 섞지 않으려고 근거의 종류로 나누었다.

## 계산·대조로 확정된 곳 (15건)

계산으로 확인되거나 두 자리가 실제로 다르게 적힌 곳이다. 판단이 들어가지 않았다.

### 19번 성취기준 코드는 존재하지 않는 번호입니다

- 위치: 19번 문항 머리 · 부록 이원목적분류표 19행 · 커버리지 목록
- 심각도: 높음

원문

```
19. [6점]  [12수학Ⅰ 03-08] · 출처 36쪽 유형12 문항34 (26054-0079) 형식 변형
```

고침

```
19. [6점]  [12수학Ⅰ03-07] · 출처 36쪽 유형12 문항34 (26054-0079) 형식 변형
```

2015 개정 수학과 교육과정(교육부 고시 제2015-74호 [별책 8])에서 수학Ⅰ 수열 영역의 성취기준은 `03-01`부터 `03-07`까지 일곱 개입니다. `03-08`은 없습니다.

19번은 수학적 귀납법으로 등식을 증명하는 문항이므로 `[12수학Ⅰ03-07] 수학적 귀납법의 원리를 이해하고, 이를 이용하여 명제를 증명할 수 있다`가 맞습니다.

같은 코드가 문항 머리, 이원목적분류표, 커버리지 목록 세 곳에 실려 있으므로 함께 고쳐야 합니다.

교육부 고시 원문 PDF는 이 환경의 네트워크 정책으로 직접 받지 못했습니다. `03-04`(∑), `03-05`(여러 가지 수열의 합), `03-06`(귀납적 정의), `03-07`(수학적 귀납법)의 문장을 각각 인용한 자료를 교차 확인해 얻은 결론입니다. 고시 원문으로 한 번 더 확인해 주시면 확실합니다.

9번과 19번이 나란히 한 칸씩 밀려 있습니다. 수열 영역을 여덟 개로 세신 것으로 보입니다.

| 03-05 | 여러 가지 수열의 첫째항부터 제n항까지의 합을 구할 수 있다 |

### 3번은 정적분 문항인데 부정적분 성취기준이 붙었습니다

- 위치: 3번 문항 머리 · 부록 이원목적분류표 3행
- 심각도: 높음

원문

```
3. [3.8점]  [12수학Ⅱ 03-02] · 출처 62쪽 유형2 문항04 (26054-0137) 변형
```

고침

```
3. [3.8점]  [12수학Ⅱ03-04] · 출처 62쪽 유형2 문항04 (26054-0137) 변형
```

`[12수학Ⅱ03-02]`는 `함수의 실수배, 합, 차의 부정적분을 알고, 다항함수의 부정적분을 구할 수 있다`입니다. 3번은 구간이 같은 두 정적분을 합쳐 계산하는 문항이므로 `[12수학Ⅱ03-04] 부정적분과 정적분의 관계를 이해하고, 다항함수의 정적분을 구할 수 있다`가 맞습니다.

같은 `03-02`를 쓴 10번과 15번은 $f'$에서 $f$를 복원하는 부정적분 문항이라 코드가 맞습니다. 3번만 어긋납니다.

### 2번은 ∑의 성질만 쓰는 문항입니다

- 위치: 2번 문항 머리 · 부록 이원목적분류표 2행
- 심각도: 중간

원문

```
2. [3.8점]  [12수학Ⅰ 03-05] · 출처 31쪽 유형7 문항19 (26054-0064) 변형
```

고침

```
2. [3.8점]  [12수학Ⅰ03-04] · 출처 31쪽 유형7 문항19 (26054-0064) 변형
```

2번은 $\sum(a_k+b_k)$, $\sum(a_k-2b_k)$의 선형성과 $\sum c = nc$만 쓰는 문항이라 `03-04`(∑의 뜻과 성질)에 해당합니다. `03-05`(여러 가지 수열의 합)는 부분합을 실제로 구하는 8번과 12번에 맞습니다.

### 커버리지 표의 "지정 14개 전부 1회 이상"이 성립하지 않습니다

- 심각도: 중간

앞의 네 건을 반영하면 실제로 출제된 성취기준은 **16개**가 되고, 목록도 달라집니다.

| 구분 | 코드 |

### 16번 채점기준의 두 항목이 같은 답안에 다른 점수를 지시합니다

- 위치: 채점기준표 16번 · [후한 적용] 2항, 3항
- 심각도: 높음

원문

```
· ④에서 한 경우만 다루었더라도 $a=10$을 얻고 ⑤의 판단이 있으면 4점.
· 절댓값을 벗기지 않고 $6+a=-(4-2a)$만으로 $a=10$을 얻은 경우도 ③④를
  인정하여 5점(경우 분류 서술 누락은 감점하지 않음).
```

두 항목이 가리키는 답안이 같습니다. `|6+a|=|4-2a|`를 세운 뒤 한 경우만 풀어 `a=10`을 얻고 양수임을 확인한 답안은 2항으로는 4점, 3항으로는 5점입니다.

경우 분류를 **덜** 쓴 답안이 오히려 1점을 더 받는 구조이기도 합니다. 채점자 두 사람이 같은 답안에 다른 점수를 줍니다.

고침 (2항을 삭제하고 3항으로 통일)

```
· 경우 분류를 서술하지 않고 $6+a=-(4-2a)$ 한 경우만으로 $a=10$을 얻은 뒤
  양수 조건을 확인했으면 ③④⑤를 모두 인정하여 5점.
· 두 경우를 모두 구했으나 양수 조건 판단이 없으면 4점.
```

### 15번 '적분상수 누락 3점'이 공통 원칙 두 개와 충돌합니다

- 위치: 채점기준표 15번 [후한 적용] ↔ 공통 채점 원칙 1, 6
- 심각도: 높음

원문

```
[공통] 1. 최종 답이 맞고 풀이의 흐름이 드러나면 세부 서술이 소략해도 만점으로 한다.
[공통] 6. 부호·괄호 오기, 기호 누락 등 결과에 영향이 없는 표기 실수는 감점하지 않는다.
[15번] · 적분상수 $C$를 빠뜨렸으나 이후 처리가 옳고 답이 맞으면 3점.
```

`f(x)=x³-2x²+6x`라 쓰고 `f(1)=5`를 확인한 뒤 `f(3)=27`을 낸 답안은 원칙 1로는 4점, 원칙 6으로는 감점 없음, 15번 항목으로는 3점입니다.

이 문항은 조건 $f(1)=5$가 정확히 $C=0$을 만들도록 잡혀 있어, 적분상수를 아예 쓰지 않은 답안도 정답 27에 도달합니다. 그래서 이 충돌이 이론이 아니라 실제 답안에서 자주 일어납니다.

15번에 한해 원칙 1·6의 예외임을 명시하거나, 조건을 $f(1)=6$처럼 바꿔 $C\ne0$이 되게 하는 편이 낫습니다.

### 17번 채점기준은 답이 틀린 답안에 만점을 줍니다

- 위치: 채점기준표 17번 [후한 적용] 3항
- 심각도: 높음

원문

```
· ⑤에서 $c$, $d$ 중 하나만 틀렸고 $f(2)$ 계산 절차가 옳으면 ⑤ 부여.
```

⑤는 이 문항 마지막 단계(1점)입니다. ①~④를 받은 답안이 $c$나 $d$를 틀리면 $f(2)\ne11$인데도 ⑤가 부여되어 5점 만점이 됩니다. 공통 원칙 1(정답이 맞아야 만점)·원칙 2(계산 실수 $-1$점)와 어긋나고, 같은 상황을 $-1$로 처리한 20번 ⑥항과도 다릅니다.

덧붙여 $c$가 틀리면 $f(1)=0$에서 나오는 $d$도 따라 달라지므로 "하나만 틀렸고"라는 상황 자체가 잘 생기지 않습니다.

고침

```
· ⑤에서 $c$, $d$를 구하는 절차가 옳고 산술 실수로 $f(2)$만 틀렸으면
  ⑤를 부여하되 공통 원칙 2에 따라 $-1$점(즉 4점).
```

### 14번 '곧바로 80'과 공통 원칙 5 사이에 경계가 없습니다

- 위치: 채점기준표 14번 [후한 적용] 1항 ↔ 공통 채점 원칙 5
- 심각도: 높음

원문

```
[공통] 5. 과정 없이 정답만 쓴 경우 배점의 1/2를 부여한다(소수점은 올림).
[14번] · ①②를 명시하지 않고 곧바로 $80$을 옳게 구했으면 4점.
```

답안에 `g'(2)=80`만 적혀 있으면 원칙 5로는 2점, 14번 1항으로는 4점입니다. "과정 없이"와 "①②를 명시하지 않고"가 같은 답안을 가리킵니다.

14번 1항이 뜻한 것은 `g'(2)=2·2·5+5·12=80`처럼 ③의 곱의 미분법이 식으로 드러난 답안으로 보입니다. 그렇다면 그 조건을 적어야 합니다.

고침

```
· 곱의 미분법을 적용한 식이 드러나 있으면 ①②를 명시하지 않았어도 4점.
  $g'(2)=80$이라는 결과만 있고 식이 없으면 공통 원칙 5에 따라 2점.
```

### 19번 '결론 문장 없으면 −1'이 이중 감점으로 읽힙니다

- 위치: 채점기준표 19번 [후한 적용] 3항
- 심각도: 중간

원문

```
· ⑤의 결론 문장이 아예 없으면 $-1$ (귀납법의 형식 요건이므로 이 항만 예외).
```

⑤ 자체가 1점짜리 단계입니다. 결론 문장이 없으면 ⑤를 주지 않아 5점인지, ⑤를 주지 않고 추가로 1점을 더 빼 4점인지 문면으로 정해지지 않습니다.

고침

```
· ⑤의 결론 문장이 아예 없으면 ⑤를 부여하지 않는다(즉 5점).
  "따라서 성립한다" 정도의 한 줄만 있어도 ⑤를 부여한다.
```

### 시험지 모범답안과 채점기준표의 단계 번호가 어긋납니다

- 위치: 16 · 17 · 18 · 20번
- 심각도: 중간

채점기준표 끝의 ※ 주석은 "채점 후에는 각 답안에 단계 번호(①~⑥)를 표시해 어느 단계까지 인정되었는지 알 수 있게 한다"라고 지시합니다. 그런데 네 문항에서 두 문서의 번호가 다른 내용을 가리킵니다.

| 문항 | 시험지 모범답안 | 채점기준표 | 어긋난 지점 |
| --- | --- | --- | --- |
| 14 | ①~④ | ①~④ | 일치 |
| 15 | ①~④ | ①~④ | 일치 |
| 16 | ①~④ (④=검산) | ①~⑤ (⑤=양수 조건 확정) | 단계 수가 다름 |
| 17 | ①~⑥ | ①~⑤ | 기준표 ⑤ = 모범답안 ⑤+⑥ |
| 18 | ①~⑥ | ①~⑤ | 기준표 ⑤ = 모범답안 ⑤+⑥ |
| 19 | (i)(ii) | ①~⑤ | 표기 체계가 다름 |
| 20 | ①~⑥ | ①~⑥ | 기준표 ①② = 모범답안 ①, 기준표 ⑥ = 모범답안 ⑤+⑥ |

### 15 · 18번은 핵심 조건을 쓰지 않아도 정답이 나옵니다

| 15 | $f(1)=5$ | $C=0$, $f(3)=27$ | $C$ 없이도 $f(3)=27$ |
| 18 | $t=k$에서 위치가 같다 | $C=-9/2$, 최댓값 $9/2$ | $C=0$이어도 최댓값 $9/2$ |

18번은 $D(t)=-\frac{t^3}{3}+\frac{3t^2}{2}+C$에서 $|D|$의 최댓값이 $D(0)$과 $D(3)$의 차 $9/2$로 정해지므로, $C$를 어떻게 두어도 답이 같습니다. 두 문항 모두 채점기준표가 그 단계에 각각 1점을 배정해 두었지만, 답만으로는 통과 여부를 구별할 수 없습니다.

### 21번은 부호를 반대로 판정해도 정답이 나옵니다

넓이가 $|5|+|-2|=7$이라 $(0,\alpha)$와 $(\alpha,4)$의 대소를 정반대로 판정한 답안도 7을 얻습니다. 채점기준표 ②⑤(2점)가 겨냥한 부호 판정이 답으로는 드러나지 않습니다.

### 21번의 '증가하는' 조건은 풀이에 쓰이지 않습니다

모범답안 어디에도 쓰이지 않는 조건입니다. 조건 자체는 모순이 없습니다. 오히려 $\alpha$의 범위를 $\sqrt5 \le \alpha \le 4-\sqrt2$로 제한하는 역할을 합니다(증가성과 $f(0)=0$, $f(4)=8$에서 나옵니다). 조건 (가)·(나)를 만족하는 증가 연속함수가 실제로 존재한다는 뜻이기도 합니다.

다만 학생 입장에서는 쓰라고 준 조건으로 읽혀 그래프를 그려 부호를 단정하는 근거로 삼기 쉽습니다.

### 19번의 난이도 '상'이 높아 보입니다

$\sum k\cdot2^k=(n-1)2^{n+1}+2$의 귀납법 증명은 수학Ⅰ 교과서 수학적 귀납법 단원의 대표 예제 수준입니다. 서술형 '상' 3문항 중 하나로 6점을 두기에는 20·21번과 난이도 차이가 큽니다.

### 오답 보기의 유인이 약한 문항이 있습니다

4·5·7번의 오답 보기는 등차로 나열되어 있을 뿐, 흔한 오류에서 나오는 값과 맞물리지 않습니다.

- 4번: $\frac18x-2$를 $\frac18(x-2)$로 읽으면 $a=2$, $\log_2 8=3$을 $a$로 착각하면 $a=3$ — 어느 것도 보기에 없습니다

특히 10번과 15번은 성취기준까지 `[12수학Ⅱ 03-02]`로 같고, "$f'(x)$가 주어진 다항함수 $f$를 부정적분으로 복원한 뒤 조건 하나로 적분상수를 정한다"는 구조가 동일합니다. 같은 문항을 난이도만 달리해 객관식과 서술형에 한 번씩 낸 셈입니다.

수능완성을 푼 학생과 그렇지 않은 학생의 차이가 같은 자리에서 두 번 벌어지기도 합니다.

### 20번 ③의 근거가 한 줄 모자랍니다

원문

```
③ $(t-3)^{2}\ge0$이므로 $f(t)+49\ge0 \iff t+6\ge0$
```

$(t-3)^2\ge0$만으로는 이 동치가 나오지 않습니다. $t=3$이면 $(t-3)^2=0$이라 $t+6$의 부호와 무관하게 성립하기 때문입니다. 결론 $t\ge-6$은 $3\ge-6$이므로 맞습니다.

고침

```
③ $t\ne3$일 때 $(t-3)^{2}>0$이므로 $f(t)+49\ge0 \iff t+6\ge0$이고,
   $t=3$은 $t\ge-6$에 포함되므로 $f(t)\ge-49 \iff t\ge-6$
```

### 16번 모범답안 ④의 표현을 다듬을 곳이 있습니다

원문

```
④ $a=10$일 때 좌극한 $=|16|=16$, 우극한 $=|-16|=16$으로 일치하므로 연속.
```

좌극한과 우극한이 같다는 것만으로는 연속이 아니고 함숫값과도 같아야 합니다. ②에서 우극한이 $|f(2)|$와 같음을 밝혀 두어 결과는 맞습니다.

고침

```
④ $a=10$일 때 좌극한 $=|16|=16$, 우극한 $=|f(2)|=|-16|=16$으로
   함숫값과 일치하므로 $x=2$에서 연속.
```

### 이원목적분류표에 행동영역 축이 없습니다

부록의 표는 번호·유형·난이도·배점·성취기준·출처·정답 일곱 칸으로 되어 있습니다. 이원목적분류표는 이름 그대로 **내용 영역**과 **행동 영역**(이해·적용·추론·문제해결 등) 두 축으로 문항을 분류하는 표인데, 지금은 내용 축만 있는 일차원 표입니다.

예상 정답률 칸도 없습니다. 시험 후 실제 정답률과 대조하면 다음 출제의 난이도 배정에 쓸 수 있습니다.

### 4번은 진수 조건만 보면 즉답할 수 있습니다

목표 함수 $y=-\log_{2}\!\left(\frac18x-2\right)$의 정의역은 $\frac18x-2>0$, 즉 $x>16$입니다. 평행이동한 그래프를 $y=x$에 대해 대칭이동한 $y=3-\log_{2}(x-a)$의 정의역은 $x>a$입니다.

두 정의역을 맞추면 **평행이동도 대칭이동도 수행하지 않고** $a=16$이 나옵니다. 이 문항이 겨냥한 그래프의 평행이동·대칭이동을 평가하지 못합니다.

진수의 계수를 $\frac18$이 아닌 값으로 바꾸거나, $a$를 정의역이 아닌 다른 자리에서 결정되게 하면 막을 수 있습니다.
