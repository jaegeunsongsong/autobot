# 강대모의고사K 23회 변형 문항 검토 결과

대상: 문제지 3종(미적분·확통·기하) + 답안지 3종. 공통 8, 9, 10, 11, 12, 13, 14, 18, 19, 20번은 세 문제지에 동일하게 수록.

## 1. 검토 방법
1. **정답 재계산**: 모든 문항을 원문 풀이와 독립적으로 sympy(기호 계산)로 다시 풀었다.
2. **수치 시뮬레이션**: 도형·넓이·확률 문항(12, 13, 14, 27미적, 28미적, 28확통, 27기하, 28기하, 29기하)은 scipy 수치적분·좌표 계산·마르코프 체인·완전탐색으로 2차 검증했다. 28확통 코드로 원문 조건을 넣으면 원문 정답 6/11이, 29확통 코드로 원문을 넣으면 88이 재현됨을 확인했다.
3. **형식 점검(스크립트)**: 세 문제지의 공통 부분이 바이트 단위로 동일한지, 각 답안지의 빠른 정답표와 문항별 풀이의 정답이 일치하는지, 5지선다 문항은 선택지가 5개·단답형은 0개인지, 선택지가 오름차순인지, 정답이 선택지에 정확히 한 번 있는지, 단답형 정답이 1~999 자연수인지 확인했다.
4. **조건 성립 점검**: 변형 후에도 원문 풀이의 논리가 그대로 성립하는지(아래 2절) 문항별로 확인했다.

## 3. 작업 중 발견하여 고친 오류
1. **미적분 28번 풀이 오류**: 처음 작성한 풀이에서 교점을 $x=-3t$로 잘못 잡아 정답이 $-\frac14e^3+\frac14e$로 나왔다. 수치 시뮬레이션에서 불일치가 드러나 $x=-\frac t3$로 바로잡고 선택지와 풀이를 수정했다.
2. **미적분 28번 선택지 순서**: 수정 후 선택지가 오름차순이 아니었다(실수 값 기준). 오름차순으로 재배열하고 정답 번호를 ③→②로 바꿨다.
3. 이전 세트에서 공통 문항을 미적분용·확통용으로 다르게 만들었던 것을, 요청에 따라 세 문제지 모두 같은 공통 문항으로 통일했다.

## 4. 2차 독립 검토(별도 검토자, 정답 비공개 상태에서 전 문항 재풀이)
- 30문항 전부 독립 재계산 결과 답안지와 일치, 정답·풀이·보기 구성·정답표 오류 0건.
- 문장은 원본과 숫자 외 차이 없음(조사·어미 불일치 없음), 배점 원본 유지 확인.
- 그림 지적 4건: 기하 29번(점 C가 포물선과 수직선의 교점으로 표시되지 않음), 미적분 26번(곡선 라벨 렌더링·시작점), 14번(라벨이 곡선과 겹침)은 수정했다. 12번은 새 수치에서 ∠A가 실제로 직각이므로 그림이 정확한 것이며 그대로 두었다(아래 5절 참고).

## 5. 남은 주의점(오류는 아니지만 알려드릴 것)
- **13번**은 문제 구조상 "숫자만" 바꾸면 원문을 정수배로 확대한 형태만 성립한다(원점을 지나는 접선 조건과 넓이 상수 조건이 동시에 맞아야 함). 2배 확대본을 썼고, 보기 ㄴ을 거짓으로 바꿔 정답 번호가 원문(⑤)과 달라지게 했다.
- **기하 27번**은 $\sin\theta$가 유리수이면서 $\overline{PA}$가 $p\sqrt2$ 꼴로 깔끔하게 떨어지는 조합이 원문의 비율(높이 = 변의 2배)뿐이어서, 수치는 바뀌었지만 **정답 값 $4/5$는 원문과 같다**. 선택지 순서를 바꿔 정답 번호는 ④→③이다.
- **그림 문항**(12, 14, 25확, 26미, 27미, 27기, 28확, 28기, 29기)은 새 수치로 좌표를 계산해 다시 그렸다(`figs/` 폴더의 SVG). 12번은 변형 수치에서 ∠A가 직각이 되어 원문과 모양이 다르다. 그림이 정확한 대신 학생이 직각을 눈치채면 피타고라스로 바로 풀 수 있으므로, 원하시면 12번 수치를 바꿔 일반 삼각형으로 만들 수 있다. 14·27미·29기는 실제 좌표로 그려 접선·접원 관계가 그림에서도 성립한다. 26미는 곡선의 높이가 작아 세로 방향을 4배 과장한 개념도이다.
- 확통 27번 정답은 소수(239.5)이며, 원문도 소수 선택지였다.
- 배점은 원문 그대로 두었다.
