# 강대모의고사K 23회 변형 문항

2027학년도 강대모의고사K 23회(홀수형)의 공통 8·9·10·11·12·13·14·18·19·20번과 선택 25~29번을 **숫자만 바꿔** 다시 출제한 문항과 답안지입니다.

| 파일 | 내용 |
|---|---|
| `미적분-문항.md/.html/.pdf` | 공통 10문항 + 미적분 25~29번 |
| `미적분-답안지.md/.html/.pdf` | 위 문항의 정답과 풀이 |
| `확통-문항.md/.html/.pdf` | 공통 10문항(미적분 세트와 다른 수치) + 확률과 통계 25~29번 |
| `확통-답안지.md/.html/.pdf` | 위 문항의 정답과 풀이 |

- 모든 문항의 정답은 sympy/scipy/완전탐색으로 기호·수치 검산했습니다. 13번은 구조상 원문을 정수배로 확대한 형태만 가능하여 미적분 세트는 2배, 확통 세트는 3배 수치를 사용했습니다.
- 그림 문항(12, 14, 25, 26, 27, 28번)은 원문 그림을 그대로 쓰고 길이·개수만 본 문항 수치로 읽습니다.
