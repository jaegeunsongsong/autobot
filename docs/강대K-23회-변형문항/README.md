# 강대모의고사K 23회 변형 문항

2027학년도 강대모의고사K 23회(홀수형)의 공통 8·9·10·11·12·13·14·18·19·20번과 선택 25~29번을 **숫자만 바꿔** 다시 출제한 문제지 3종과 답안지 3종입니다. 공통 10문항은 세 문제지에 동일하게 들어갑니다.

| 파일 | 내용 |
|---|---|
| `미적분-문항` / `미적분-답안지` | 공통 10문항 + 미적분 25~29번 / 정답과 풀이 |
| `확통-문항` / `확통-답안지` | 공통 10문항 + 확률과 통계 25~29번 / 정답과 풀이 |
| `기하-문항` / `기하-답안지` | 공통 10문항 + 기하 25~29번 / 정답과 풀이 |
| `검토-결과.md` | 검토 방법, 문항별 확인 사항, 발견·수정한 오류, 주의점 |

각 문서는 `.md`(원본), `.html`(브라우저용, 수식 MathML), `.pdf`로 제공합니다.
