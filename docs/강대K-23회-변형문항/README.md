# 강대모의고사K 23회 변형 문항

2027학년도 강대모의고사K 23회(홀수형)의 공통 8·9·10·11·12·13·14·18·19·20번과 선택 25~29번을 **숫자만 바꿔** 다시 출제한 문제지 3종과 정답·해설 3종입니다. 공통 10문항은 세 문제지에 동일하게 들어갑니다.

| 파일 | 내용 |
|---|---|
| `미적분-문제지.pdf` / `미적분-정답및해설.pdf` | 수능 양식(A4 2단, 7쪽) 문제지 / 정답·해설 |
| `확통-문제지.pdf` / `확통-정답및해설.pdf` | 〃 (확률과 통계) |
| `기하-문제지.pdf` / `기하-정답및해설.pdf` | 〃 (기하) |
| `*-문항.md`, `*-답안지.md` | 원본(마크다운+LaTeX). PDF는 여기서 생성 |
| `*.html` | PDF와 같은 내용의 HTML(수식 MathML) |
| `figs/` | 그림 문항 9개의 새 수치 기준 SVG |
| `검토-결과.md/.pdf` | 검토 방법, 문항별 확인 사항, 발견·수정한 오류, 주의점 |

PDF 재생성: `python3 tools/build_exam.py` 후 Chromium headless로 각 `.html`을 인쇄(`--print-to-pdf`).
